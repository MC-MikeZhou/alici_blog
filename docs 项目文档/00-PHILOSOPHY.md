# 00 - 为什么是 Claude Code + Skills？

> 从"对话式 AI"到"文件式操作系统"的范式转移

---

## 一、当前 AI 协作的核心痛点

2024 年底，Andrej Karpathy 指出了大语言模型的根本缺陷：

> **LLM 缺乏持久上下文，无法成为团队的"大脑"。**

这导致了一个普遍现象：

```
团队知识分布现状：

Basecamp     ──┐
Slack        ──┼──→  碎片化  ──→  AI 无法有效处理
Google Docs  ──┤
Notion       ──┤
本地文件     ──┘

结果：每次对话都要从零开始解释背景
```

无论是 ChatGPT 还是早期的对话式 AI，都无法解决这个问题。每次新对话，上下文归零。

---

## 二、三种 AI 协作模式对比

| 维度 | 对话式 AI | Agent 平台 | Claude Code + Skills |
|------|----------|------------|---------------------|
| **代表** | ChatGPT 网页版 | Zapier AI, AutoGPT | Claude Code CLI |
| **上下文** | 单次对话，用完即失 | 平台托管，锁定在服务里 | 本地文件，永久可用 |
| **知识存储** | 无 | 平台数据库 | Markdown 文件 |
| **可迁移性** | 无法导出 | 依赖平台 | 复制文件夹即可 |
| **可组合性** | 手动复制粘贴 | 有限的工作流 | Skills 无限嵌套 |
| **所有权** | 平台拥有 | 平台拥有 | **你拥有** |
| **100年后** | 平台关闭则消失 | 平台关闭则消失 | **文件依然可读** |

## 三、Claude Code 的三个关键突破

### 突破 1：编码能力 = 通用连接能力

传统认知：编码 = 写程序
新认知：**编码 = 创造系统之间的连接**

```
传统对话式 AI：
"帮我写一个爬虫" → 输出代码文本 → 你手动运行 → 可能报错 → 再问 AI

Claude Code：
"帮我写一个爬虫" → 自动写代码 → 自动运行 → 自动调试 → 直接交付结果
```

这不只是"更方便"，而是质变：

- **它能直接创造工具**（不只是描述工具）
- **它能连接系统**（不只是翻译指令）
- **它能持续工作数小时**（不只是一问一答）

### 突破 2：MCP 让工具可组合

MCP（Model Context Protocol）是 Anthropic 提出的开放协议：

```
传统集成：
每个工具 ←→ 每个 AI = N × M 种集成方式

MCP 模式：
所有工具 ←→ MCP ←→ 所有 AI = 1 种标准接口
```

类比：MCP 就像 USB-C 接口，统一了 AI 与外部工具的连接方式。

在我们的 AI 工厂里：
- FAL.ai 图片生成 → 通过 MCP 接入
- Framer CMS → 通过 MCP 接入
- Google Analytics → 通过 MCP 接入

**工具之上还能叠加工具**，这就是 Skills 的可组合性。

### 突破 3：本地化带来的平移自由

```
场景：Sam 开发了 AliciBlog 系统

传统方式：
Sam 开发 → 部署到服务器 → 其他人通过网页访问 → 依赖服务器在线

Claude Code 方式：
Sam 开发 → 打包成文件夹 → Hans 复制到本地 → 直接运行

平移成本：复制粘贴
```

这种"本地应用"模式带来了前所未有的自由度：

- **不依赖网络**：离线也能工作
- **不依赖平台**：没有账号锁定
- **不依赖他人**：文件在手，能力在手

## 四、"文件胜过应用"的产品哲学

Obsidian 创始人 Kepano 的核心观点：

> **Apps are ephemeral, but your files have a chance to last.**
> 应用是短暂的，但文件有机会持久。

他用埃及象形文字做比喻：

```
石头上的符号 > 雕刻它的凿子

你创造的文件 > 你使用的工具
```

### 应用到 AI 工厂

| 类比 | 传统 | AI 工厂 |
|------|------|---------|
| 凿子 | SaaS 应用 | Claude Code |
| 石刻 | 锁在平台里的数据 | 本地 Markdown 文件 |
| 神庙 | 平台关闭则消失 | 文件夹可永久保存 |

我们的设计原则：

```
1. 所有知识 → Markdown 文件（纯文本，永远可读）
2. 所有配置 → JSON/YAML（开放格式）
3. 所有产出 → 标准格式（HTML/PNG/JSON）
4. 所有流程 → SOP 文档（人和 AI 都能读）
```

**即使 Claude Code 消失，Anthropic 倒闭，你的工厂蓝图依然可用。**

## 五、新的操作系统视角

Claude Code 不只是"更强的 AI 助手"，它是一种**新的计算范式**：

```
┌─────────────────────────────────────────────────────────────┐
│                    Claude Code 操作系统                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   传统 OS              →        Claude Code OS              │
│   ─────────────────────────────────────────────            │
│   文件系统             →        Skills + 规范文档           │
│   进程管理             →        Agent 调度                  │
│   Shell 命令           →        自然语言                    │
│   系统调用             →        Tool Use                    │
│   共享库 (.so/.dll)    →        共用 Skills                 │
│   守护进程             →        Agents                      │
│   用户态/内核态        →        人工节点/自动流转            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

关键洞察：

- **自然语言就是编程语言** — 规范文档即源代码
- **文件就是程序** — Skills 是可执行的 Markdown
- **对话就是进程** — 压缩机制实现虚拟内存
- **MCP 就是设备驱动** — 标准化连接外部系统

## 六、AI 工厂的本质

会议纪要里 Hans 说：

> **"我们缺的不是工具，缺的是让工厂运转起来的机制。"**

机制 = **可执行的档案**

```
传统档案：写下来 → 未来可以被人阅读
AI 档案：写下来 → 未来可以被 AI 执行

我们的 Skills 和 SOP 不只是文档
它们是可以被任何理解自然语言的系统执行的程序
```

这比代码更持久：
- Python 2 → Python 3 让多少代码报废？
- 但自然语言写的规范，10 年后依然可读可执行

## 七、为什么选择这条路？

### 短期价值

| 指标 | 当前 | 目标 |
|------|------|------|
| 单篇生产时间 | 2-4 小时 | 30 分钟 |
| 人工介入次数 | 7+ 次 | 2 次 |
| 自动化比例 | 0% | 70% |
| 月产量 | 5 篇 | 30 篇 |

### 长期价值

1. **知识不再流失** — 人员变动，Skills 留下
2. **能力可以复制** — 新生产线，复制 Skills 即可
3. **资产真正属于你** — 不锁定在任何平台
4. **可传承给未来** — 100 年后文件依然可读

## 八、总结：从手工坊到数字神庙

```
过去：团队知识 → 在人脑里 → 人走知识散

现在：团队知识 → 在 SaaS 里 → 平台关则散

未来：团队知识 → 在文件里 → 永久可用，AI 可执行
       ↑
       我们正在建造的
```

我们不只是在建造一个"AI 工厂"，我们是在建造一座**数字神庙**：

- **Skills** 是刻在石头上的咒语
- **SOP** 是祭司的操作手册
- **规范文档** 是神庙的设计图纸
- **Claude Code** 只是当前这一代的凿子

凿子会换，石刻永存。
