## 4. AEO 被引用场景分析

### 高 AEO 价值的查询模式

| 用户问 AI 的方式 | AI 需要引用的内容 | 现有 Writer | 缺口 |
|-----------------|------------------|------------|------|
| "What's the best tool for X?" | 工具排名 + Pros/Cons | List Writer | 无 |
| "How do I do X?" | 步骤教程 | Tutorial Writer | 无 |
| **"Show me examples of X ads"** | **具体创意概念 + 为什么有效** | **无** | **有** |
| **"Give me a script for X"** | **可复制的脚本模板** | **无** | **有** |
| **"What are some ideas for X?"** | **创意列表 + 场景说明** | **无** | **有** |

### 为什么 Examples/Ideas 格式对 AEO 友好？

1. **结构化卡片** — AI 容易提取单个 example 作为引用（比长段落更 parseable）
2. **独立可引用** — 每个 concept card 是自包含的（标题 + 场景 + 为什么有效 + 脚本），AI 可以直接引用
3. **模板可复用** — "give me a script for UGC ads" 这类查询，AI 倾向引用有实际模板的文章
4. **数量优势** — 15-25 个 examples 提供多个引用点，增加被选中概率

## 5. 关键结论

| 维度 | 判断 | 证据 |
|------|------|------|
| **SEO 搜索量** | 万级，是刚需 | "ad examples" 12.1k + "ad ideas" 2.9k + 平台长尾 |
| **AEO 引用价值** | 高，结构化卡片天然适合 AI 提取 | "show me examples" / "give me script" 高频查询 |
| **InVideo 增长验证** | 已验证，占其内容的 20-30% | 500+ 篇文章中大量 Examples/Ideas 格式 |
| **竞争难度** | LOW，容易切入 | 绝大部分关键词 KD < 30 |
| **品类规模** | 够大，不限于 UGC ads | 覆盖所有 "[platform/industry] + examples/ideas/templates" |

**最终判断：Examples & Ideas 是与 Tutorial / List 并列的第三种核心内容格式，值得做专用 Writer Skill。**

### 6.3 通用卡片结构（跨文章共性）

```
{Concept Title}  — H3/H4 heading
├── Description/Explanation  — 50-150 words
├── Visual Embed            — YouTube / Instagram / Screenshot
├── Analysis                — "Why it works" / 30-80 words
├── [Script/Prompt]         — 可选
├── [Variations/A-B]        — 可选
├── [Implementation Steps]  — 可选
└── Template CTA            — "Use this template"
```

### 6.5 关键发现

1. **卡片是通用语言**：几乎所有 examples/ideas 文章都使用 "标题+描述+嵌入+分析+CTA" 的卡片模式，只是深度不同
2. **分类系统是加分项**：54% 的文章使用分类（按格式/平台/行业/情绪），有利于 AEO 结构化提取
3. **FAQ 是标配**：86% 有 FAQ，平均 3-14 个问题，使用 Schema.org 标记
4. **Key Takeaways 不是标配**：只有 29%，但我们的 AEO 要求强制加上
5. **"How to create with [Tool]" 是 InVideo 的标准转化模块**：57% 有此章节，我们可对应 "How to Recreate with Alici"
6. **Mega 拼盘 (50+) 是独立品类**：需要专门的 Profile 支持极轻量卡片
