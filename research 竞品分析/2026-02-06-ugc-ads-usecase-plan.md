# InVideo 对标打法：用“已验证的 SEO 文章形态”承载 Alici 小 use case（UGC Ads / Beauty / TikTok-Reels）

## Summary（目标与结论）

- 你的担心是对的：InVideo 的 **blog 主打法不是“单个小 use case 一篇文章”**；他们把“小颗粒内容”更多放在 **landing（/make）**、**help center**、以及 **长文里的 examples/templates 模块**。
- 因此我们不走“新路”，而是 **复刻 InVideo 的信息架构**：
  - Blog 用已验证形态（Examples / Ideas / A/B testing workflow）吃 SEO + AEO；
  - Alici 的 use case 作为这些文章里的“示例/模板资产”，并承接更深内容与转化（use case 服务于 blog）。

## Success Criteria（验收标准）

- **SEO**：每篇 blog 都有清晰 primary keyword + 6–12 个长尾子意图，且每个 use case 被至少 1 篇 blog 作为 example 引用并内链回去。
- **AEO**：每篇 blog 与每个 UGC 专用 use case 页的顶部都能在 120 字内给出“直接答案 + 适用场景”，并包含可复制模块（脚本/镜头表/字幕）。
- **内容生产可规模化**：新增的 UGC use case 页全部遵循统一结构（下面给出），能被后续批量扩展到 20+。

## Phase 1 — 定义 3 套“对标即模板”（不做选择题，直接锁定）

### Template 1：Blog（Swipe File / Examples）——承载多个 use case

1. 120 字内 Direct answer
2. Key Takeaways（3–6 条）
3. Examples（卡片写法；每卡都链接到对应 Alici use case 详情页）
4. How to recreate with Alici（通用 prompt + 变量槽位）
5. Mini FAQ（4–6 个）

### Template 2：Blog（Ideas + Templates）——每个 idea 就是一个“微 use case”

- Idea #n：What it is → Why it works → Script snippet → Shot list → On-screen text → CTA → “Try it in Alici”（链接到 use case）

### Template 3：Use Case Page（UGC 专用版本）——服务 blog 的“资产页”

- Above the fold
  - 1 句定位（谁用、做什么广告、时长、平台）
  - Copy/paste Alici prompt（v1）
  - Output spec（9:16、15s/30s、是否口播/字幕、风格）
- Core assets
  - Script（含 hook/claim/proof/CTA）
  - Shot list（逐镜头）
  - On-screen text（逐镜头）
  - 3 Variations（hook / offer / proof）
- Trust & safety
  - Do / Don’t
- FAQ（2–4 个）

## Phase 3 — 内链与站点结构（保证“小 use case 不会孤岛化”）

- Blog → Use case：每个 example 卡片链接到对应 use case 详情页
- Use case → Blog：use case 页底部放 Related swipe files/scripts
- 聚合页：新增 UGC Ads + Beauty/Skincare 入口（或二级聚合页 /use-cases/ugc-ads）

## Phase 4 — Validation（AEO/SEO 验证闭环）

- SEO：每篇 blog 出 1 个 keyword brief（primary + secondary + intent + SERP 模式）
- AEO：发布前检查（开头 120 字直答；takeaways/表格/FAQ；example 可复制）

## Assumptions & Defaults（已选择的默认项）

- 英文；blog 优先；use case 服务于 blog 素材与转化
- 受众：UGC creators；平台：TikTok/Reels；行业：Beauty/Skincare
- 大词由 Swipe file / Ideas / Workflow 承载；小页承接长尾与转化
