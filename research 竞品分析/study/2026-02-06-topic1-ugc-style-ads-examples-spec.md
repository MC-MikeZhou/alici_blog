## 2) Article type abstraction (editorial taxonomy)

### Proposed content type name

**Swipe File (Examples + Templates)**

### Definition

A “Swipe File” article is a curated set of ad examples where each example is an actionable template:
- Hook + Script + Shot List + On-screen text + Variations
- Designed for copy/paste and fast iteration
- Not a ranking listicle (“best/top”), not a pure how-to without assets

### Why this is a first-class type (like InVideo’s concentrated categories)

InVideo’s blog concentrates around:
- Examples/Swipe files (Instagram ads examples, Facebook ad ideas)
- Templates/Ideas (product video ideas with templates, testimonial ideas)
- Workflows/How-to (commercial product video, A/B testing variations)

We should treat Swipe File as its own repeatable “article product” so it’s easy to scale and editor can enforce consistent quality.

### Editor checklist for Swipe File type (internal)

- Title includes year (2026/2027)
- Above-the-fold: Hero + Key Takeaways + direct answer
- At least 10 examples; each example contains 5 fixed fields (Hook/Script/Shot list/Text/Variations)
- At least 2 tables total:
  - Workflow selector (examples index)
  - Troubleshooting table (common issues + fixes)
- Must include a “How to adapt” section: change ONLY one variable per iteration (hook/offer/proof)
