## Templates & examples (copy-paste)
Below are 6 templates. Each includes: hook → body → CTA + a shot list.

### Template 1: Product Demo (Product-in-Hand style)
**Best for:** ecommerce products with clear “show, don’t tell” benefits  
**Hook (on-screen text):** “I didn’t expect this to work, but…”  
**Voiceover script:**
- “Quick demo: here’s how I use [PRODUCT] for [JOB].”
- “The problem: [PAIN] used to take me [TIME/COST].”
- “With [PRODUCT], I get [BENEFIT] because [MECHANISM/FEATURE].”
- “If you’re dealing with [PAIN], try [PRODUCT].”
**CTA:** “Use code [CODE] for [OFFER].”
**Shot list (9:16):**
1. Close-up: product in hand (0–2s)
2. Problem moment (2–5s)
3. Demo step 1 (5–9s)
4. Demo step 2 + proof (9–14s)
5. Before/after (14–18s)
6. CTA end card (18–22s)

### Template 2: Testimonial (Founder/Customer voice)
**Best for:** higher-consideration products  
**Hook:** “I was skeptical until I tried [PRODUCT]…”  
**Script:**
- “I bought it because [REASON].”
- “The first thing I noticed: [SPECIFIC DETAIL].”
- “After [TIME], the result was [OUTCOME].”
- “If you want [DESIRED OUTCOME], this is worth a try.”
**CTA:** “Get it here: [URL]”
**Shot list:**
1. Talking head (0–7s)
2. Cutaway: product close-ups (7–12s)
3. Proof overlay (review snippet, policy-safe) (12–16s)
4. CTA end card (16–20s)

### Template 3: Unboxing + first impression
**Hook:** “Unboxing [PRODUCT]—here’s what surprised me.”  
**Script:**
- “Packaging is [DETAIL].”
- “It comes with [WHAT’S INCLUDED].”
- “First test: [DEMO].”
- “My honest take: [ONE-LINE VERDICT].”
**CTA:** “Save this for later / link in bio.”
**Shot list:**
1. Unboxing (0–6s)
2. What’s included (6–10s)
3. First test (10–17s)
4. Verdict + CTA (17–22s)

### Template 4: Before/After transformation
**Hook:** “Before vs after using [PRODUCT] for [TIME].”  
**Script:**
- “Before: [PAIN/STATE].”
- “What I changed: [PRODUCT] + [HABIT].”
- “After: [RESULT].”
- “Here’s exactly how to start: [STEP].”
**CTA:** “Start with [ENTRY OFFER].”
**Shot list:**
1. Before clip (0–3s)
2. Product action (3–10s)
3. After reveal (10–15s)
4. Steps overlay (15–20s)

### Template 5: Problem → Solution (3 bullets)
**Hook:** “If you struggle with [PAIN], do this.”  
**Script (bullets on screen):**
- “1) [TIP/STEP]”
- “2) [TIP/STEP]”
- “3) Use [PRODUCT] to [BENEFIT]”
**CTA:** “Try [PRODUCT] today.”
**Shot list:** fast cuts + text overlays; keep each shot 1–2s.

### Template 6: Offer stack (value + urgency)
**Hook:** “[OFFER] ends tonight—here’s why I’d grab it.”  
**Script:**
- “You get: [BENEFIT 1], [BENEFIT 2], [BONUS].”
- “This helps if you want [OUTCOME].”
- “My favorite part: [DETAIL].”
- “Use code [CODE] before [DEADLINE].”
**CTA:** “Shop now.”
**Shot list:** product b-roll + offer overlay + clean end card.

## FAQ (query-shaped, short answers)
### What is a UGC ad?
A UGC ad is a short-form video ad that looks and sounds like creator content—often featuring a simple demo, a personal story, or a testimonial-style script.

### Do UGC ads need a real creator?
Not always. Many brands use creator partnerships, but you can also produce UGC-style scripts and videos in-house as long as you’re honest and follow platform policies.

### How do I make UGC ads with Alici?
Add your product brief, pick a format (testimonial, demo, unboxing, before/after), and generate scripts + shot lists. Then create variants to test different hooks and offers.

### Can I generate multiple versions for TikTok/Reels/Shorts?
Yes—create multiple hooks/angles and export versions optimized for 9:16 short-form placements.

### What should I include in a UGC ad script?
A strong hook, a clear benefit, one proof point, and a simple CTA—plus on-screen text cues for pacing.

### How long should a UGC ad be?
Start with 15–30 seconds for most short-form placements, then test shorter/longer variations based on performance.

### Is it okay to use AI-generated UGC-style videos?
It can be, if you avoid deception, don’t impersonate real people, and follow platform policies and ad disclosure rules.

### Can I use customer reviews in my ads?
Only if you have the rights/permission and the claims are accurate. Keep it compliant and avoid misleading edits.

### What platforms is this best for?
TikTok, Instagram Reels, YouTube Shorts, and Meta placements—anywhere short-form creative iteration matters.

### What’s the fastest way to start?
Generate one script from your product brief, then create 3–5 hook variants and test them as separate creatives.

## Compliance notes (must-have)
- Don’t impersonate real individuals or create deceptive endorsements.
- Use disclosure where required (e.g., “ad,” “sponsored,” or platform-specific labels).
- Follow platform ad policies for restricted categories and claims.
