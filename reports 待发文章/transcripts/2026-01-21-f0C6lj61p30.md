## Key Points Extracted

### Match Image vs Match Video Modes

| Feature | Match Image | Match Video |
|---------|-------------|-------------|
| Max Duration | 10 seconds | 30 seconds |
| Priority | Character consistency (textures, facial features) | Exact skeletal movement & camera trajectory |
| Character Handling | Deforms static pixels while preserving identity | May stretch/change proportions to match reference |
| Camera Movement | May invent camera movements | Accurately renders spatial movements |
| Best For | Preserving character details | Copying exact motion |

### Workflow Steps

1. **Generate character image** with Nano Banana Pro (2K resolution, 4 outputs)
2. **Create reference motion video** (if needed) using neutral pose starting frame
3. **Apply Motion Control** with Kling 2.6 - choose Match Image or Match Video mode
4. **Text prompts are optional** - they only affect background/lighting, not motion

### Pro Tips

- Use neutral pose ("arms by side") for starting frames to allow more movement range
- Reference videos dictate ALL motion - text prompts don't control action
- Match Video mode produces still output if reference video is static
- Match Image mode often invents camera movement even from static reference
