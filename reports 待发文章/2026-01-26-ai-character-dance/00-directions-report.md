### 为什么模拟数据失败？

**1. 关键词发明问题**

许多关键词是"发明的短语"，不反映真实用户搜索行为:
- ❌ "AI character dance videos for TikTok" - 用户不会组合所有这些词
- ❌ "animated mascot videos for brands" - 营销术语，不是搜索语言
- ❌ "bulk create character animations" - 功能导向，不是用户导向

**2. 长尾过度估计**

```
父词:     "AI character animation" → 140 volume ✅
模拟子词: "professional AI character animation" → 780 (模拟) ❌
真实子词: "professional AI character animation" → 0 (真实) ✅
```

**教训**: 除非父词有 >10K 搜索量，否则长尾需求不存在。

**3. 市场成熟度误判**

市场处于 **Stage 1: Discovery**，不是 **Stage 3: Evaluation**:
- 没有品牌搜索 ("best tools", "reviews")
- 没有对比搜索 ("X vs Y")
- 没有教程搜索 ("how to", "tutorial")
- 只有基本定义搜索 ("AI character animation")

**4. 平台特定查询失败**

社交平台用户不在 Google 搜索平台特定内容:
- "TikTok 吉祥物舞蹈趋势" → 0 volume
- "Instagram 角色动画创意" → 0 volume

**原因**: 用户在平台内发现内容，不通过 Google。
