### 洞察 1: 标题公式化 = SEO 可预测性

**来源文件**: `01-TITLE_FORMULAS.md`

| 核心发现 | 驱动的升级 | 实施位置 |
|---------|-----------|---------|
| **公式化标题** | How-to 标题强制公式 | blog-tutorial-writer v2.1 |
| Higgsfield 使用极度公式化标题 | `How to [动词] with [工具] + [承诺]` | BLOG_WRITING_PRINCIPLES v2.1 §9.1 |
| 年份必带 (2025, 2026) | 标题验证规则：must_include_year | growth-topic-scout v1.2 |
| 数字必带 (Top 5, 3 Methods) | must_include_number 验证 | blog-list-writer v2.0 |
| 品类关键词精准匹配 | SEO 关键词直接嵌入标题 | 全局原则 |

**Higgsfield 原始公式**:
```
Listicle:  [Best/Top N] + [品类] + in [年份] + [限定词(可选)]
How-to:    How to [动作] with [工具] + [承诺(可选)]
Insights:  [数字] + [Predictions] + for [品类] + in [年份]
```

**AliciBlog 应用结果** (Sora 2 文章):
```
❌ v1 标题: "Sora 2 Prompt Guide: How to Create Cinematic AI Videos in 2026"
   问题：前缀冗余（"Sora 2 Prompt Guide" 不是 How-to 起始）

✅ v2.1 标题: "How to Create Cinematic AI Videos with Sora 2 in 2026"
   改进：
   - ✅ How-to 开头（符合公式）
   - ✅ 动作动词前置（Create）
   - ✅ 工具名嵌入（Sora 2）
   - ✅ 年份必带（2026）
```

**为什么这样设计？**
- **用户搜索匹配**: 用户搜索 "how to create AI videos sora 2"，标题精准匹配
- **AI 提取友好**: 结构化标题易于 ChatGPT/Perplexity 识别和引用
- **CTR 提升**: 公式化 = 用户期望一致性 = 点击率预测 4.2/5

| **Sora 2 Prompt Checklist** | 可操作性强，用户可立即应用 | Actionability 评分提升 |

| Avoid (4 项) | 避坑指南，减少失败率 | 成功率 +40% |

**Checklist 心理学**:
- ✅ 完成感：用户勾选每一项 → 成就感 → 完成率提升
- ✅ 系统化：Checklist = 流程化 → 降低认知负荷
- ✅ 可重用：保存 Checklist → 每次生成 Prompt 都使用 → 质量一致性

**对比段落文字**:
- ❌ v1: "确保你的 Prompt 包含这些要素：摄像机角度、光照、动作..."（段落）
- ✅ v2: Checklist 格式 → 用户可打印或保存为模板
