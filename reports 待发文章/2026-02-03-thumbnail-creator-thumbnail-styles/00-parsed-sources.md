## Source A — vidIQ: “Find the Best YouTube Thumbnail Styles for Your Channel”

### 维度一：核心内容（它在说什么）
- 核心论点：缩略图“风格/模板”应当从 **内容目标（entertain/educate/evoke emotion）** 出发，再参考竞品建立可复用的视觉要素，最后通过测试与数据复盘逐步固化。
- 关键概念（可直接复用的定义）：
  - “Thumbnail is a promise”：缩略图是对内容的承诺（后文可用于 anti-clickbait 章节）。
  - 内容目标三分法：娱乐 / 教育 / 情绪唤起 → 不同目标对应不同信息密度与视觉取向。
- 结构拆解（写作骨架）：
  1) 先定内容目标
  2) 看竞品提炼要素（font/color/text/expressions/composition）
  3) 面向目标受众优化（不是“好看”，是“对这群人可点”）
  4) 测试 + 复盘（CTR/watch time/retention 作为信号）
  5) 给 3 个创作者“风格匹配内容目标”的例子（Zoe Sugg / JStu / Nino’s Home）

### 维度二：背景语境（为什么这么说？可信吗？）
- 作者/机构：vidIQ（工具/服务提供商）→ 有产品立场，但内容属于行业常见实践总结。
- 发布时间：原文 2023-04-04，声明已更新。
- 潜在假设：
  - 读者是 YouTube 创作者，且可以持续迭代优化。
  - “测试能带来答案”，而不是一次就做对。

### 维度三：批判性审视（漏洞/局限）
- 没有给出可复制的 **具体模板参数**（比如字号、边距、安全区、对比检查方法）→ 我们可以补齐成 checklist。
- 例子偏“风格感受”描述，缺少“如何复刻”的操作细节 → 我们用 pattern table 把“可复制动作”写出来。
- 提及 CTR/数据指标但不提供基准与边界 → 我们需用“signals not guarantees”措辞，避免虚假承诺。

### 维度四：价值提取（可复用框架）
- 框架：**Goal → Reference → Audience → Test → Lock**
- 可复用产物：
  - “视觉要素备忘录”：字体、配色、文案长度、表情、构图规则
  - “目标-模板映射”：不同内容目标对应不同模板（Vlog/教程/挑战/ASMR）

### 维度五：写作技巧（结构/技巧）

## Source B — TubeBuddy: “11 killer YouTube thumbnail tips … inspired by big creators”

### 维度一：核心内容
- 核心论点：缩略图的点击来自 **注意力争夺**（颜色/清晰度/情绪/对比/故事/动作）+ **一致性**（品牌）+ **测试**（迭代）。
- 11 条 tip 可被我们重组为 4 个“原则簇”：
  1) Attention (contrast, color)
  2) Clarity (high-res, minimal text, single focal point)
  3) Emotion/Story (faces, narrative contrast, action freeze)
  4) Iteration (A/B testing, mobile+TV optimization)

### 维度二：背景语境
- TubeBuddy（工具/服务提供商）→ 有产品立场，但 tip 属于经验性总结。
- 发布时间：2024-12-18
- 潜在假设：
  - 大多数创作者缺一个“可持续迭代”的流程，而不是缺设计灵感。

### 维度三：批判性审视
- 强调“提升 CTR”等措辞较多，但缺少明确边界/条件 → 我们在写作中要：
  - 只说“可能提升/常见做法/可观察信号”
  - 用“first 30 seconds alignment”强调反 clickbait
- 部分段落像视频转写混入（可读性下降）→ 我们提炼成表格与 checklist，提升可引用性。

### 维度四：价值提取
- 框架：**Make it pop → Make it clear → Make it feel → Make it repeatable**
- 可复用模板：
  - 文案：2–4 个词 + 与标题互补
  - 对比：before/after、with/without、then/now（并强调方向一致：左 before、右 after）

### 维度五：写作技巧
- 列表型内容天然适合 AEO（短答案 + 可引用规则）。

### 维度六：SEO/AEO 信号
可设计的 citable blocks：
- “11 tips condensed” 一页表格
- “Mobile + TV checks” 清单
- “A/B test loop” 步骤（HowTo）

### 维度七：可复用元素
- “faces trigger attention” 的引用线索（文中提到研究链接）→ 我们在证据包里保留该引用位（不做夸大推断）。

### 维度八：品牌适配
把 tip 变成工具化流程：
- 生成多版本（变 1 个变量），快速对比
- 保存模板与资产（脸/字体/色板/背景）形成“可复用系统”
