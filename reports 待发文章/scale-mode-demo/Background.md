# Scale Mode - 背景信息

> 日期: 2026-01-24

## 核心背景

- AliciBlog 已形成稳定生产链路：smart-launcher 双轨 → Writer → Editor → AEO → 竞品验证 → Framer。
- 竞品对标发现：InVideo 已沉淀 300-500 篇内容，按搜索意图分层，可复用的方法论值得系统性借鉴。
- 规模化诉求：在独立开发者模式下，时间是核心瓶颈，需要“用 token 换时间”。

## 关键启示

- Skill 系统是自动化核心引擎：通过规范封装，实现批量改写同时保证质量下限。
- 权威外链引用能形成正向循环：引用权威 → 自身权威 → 被 AEO 引用。
- 批量重构需以“高质量参考”为起点，而非从零生成。

## 现存问题

- 博客文章部分链接需要登录才能访问，影响 SEO 与用户体验。
- Landing 默认模式为 Sora，新功能不可见，影响首访体验。
- 超长内容质量控制仍依赖结构而非细节。

## 方向性结论

- 启动“双线并行”：高质量原创 + 批量重构。
- 批量内容优先规模与基础规范，质量线由 Skill 保证。
- 内部链接映射表需提前准备，以便自动替换。
