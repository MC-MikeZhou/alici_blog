# Skill - Scale Demo (临时实验版)

> 版本: v0.1 (临时)
> 日期: 2026-01-24
> 位置: /Scale Mode/
> 目的: 用于“批量重构”小规模实验（10 篇候选）

## 1. 目标

在不依赖旧 Skill 体系的前提下，快速完成以下流程：

- 搜索与整理：从 InVideo 找到高价值候选并映射到“服务线 Demo”Skill 名称
- 评分与决策：给每篇内容打分，决定是否进入批量重构
- 提交报告：输出可执行建议与重构挑战

## 2. 输入

- 候选来源: InVideo 高质量内容样本（来自 competitive-research/invideo-blog）
- 限制: 仅做 10 篇候选的 Demo

## 3. 输出

- Demo Candidate List (10)
- Demo Scorecard
- Demo Report (含挑战评估)

## 4. 评分维度（建议）

- 搜索意图强度（1-5）
- 商业价值/转化可能性（1-5）
- 结构可复制性（1-5）
- 数据依赖复杂度（1-5，反向）
- 资产复杂度（图表/视频/交互）（1-5，反向）

总分 = 前三项加权 - 后两项惩罚

## 5. 规则约束

- 仅筛选“结构明确 + 可快速替换”的内容类型
- 内容不追求极致，但必须可通过 Skill 基础规范
- 候选必须可落地在 Alici 现有 Writer 类型之一
