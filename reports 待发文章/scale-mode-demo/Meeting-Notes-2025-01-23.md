# 会议纪要 - competitive-research

> 日期: 2025-01-23
> 参会人: Hans / Sam / Dancy
> 主题: InVideo 竞品洞察与批量重构

## 洞察与启示

### 关键洞见

- InVideo 内容策略值得系统性借鉴：已有 300-500 篇内容，按搜索意图分层组织。
- Skill 系统是内容自动化核心：可批量改写且保证质量底线。
- 权威数据引用形成正向循环：引用权威 → 自身权威 → 被 AEO 引用。
- “用 token 换时间”：AI 批量生成是独立开发者提高产能的关键手段。

### 发现的问题

- Blog 文章链接需登录才能访问，影响用户体验与 SEO。
- Landing 页默认模式为 Sora，新功能（如 Motion 2.6）不可见。
- 长文章质量仍主要依赖结构判断，细节掌控不足。

### 后续启示

- 建立“双线并行”生产模式：高质量原创（Hans + Dancy）+ 批量重构（Sam）。
- Skill 系统持续迭代，每人维护自己使用的 Skill。
- 内容生产优先高质量对标参考，再改写而非从零创作。

## 讨论纪要

### 1. 功能进度更新

- Sam：认证功能基本完成；Wan 2.6 仅剩 UI 与定价，预计当天上线；Banana 功能讨论热度高。
- Hans：Image 页面需支持不登录访问；模式选择界面可参考 Taskfile Image。

结论：Wan 2.6 今日上午/中午上线；Banana 作为后续增强点。

### 2. Landing 页面默认模式调整

- Hans：默认 Sora 导致新功能不可见，建议切换到 Motion。
- Dancy：同意。

结论：2.6 上线后默认模式从 Sora 切换为 Motion。

### 3. 博客文章链接规范

- Hans：AI Baby 文章部分链接需登录；CTA 卡片需跳转到带 motion 模板页。
- Dancy：部分链接为人工替换，可能有遗漏；已改为可追踪链接。
- Sam：追踪链接可标记用户渠道并记录积分。

结论：所有文章链接必须无需登录可访问；统计以 GA 与 Freeze Frame 后台为主。

### 4. 批量重构系统（核心议题）

- Hans：InVideo 有 300-500 篇内容可洗稿；关键是 Skill 自动替换链接、更新年份；内容选择需评分系统；Sam 主导自动化线。
- Sam：选题与分类是关键；可考虑爬取整站；Skill 规范已约束质量。
- Dancy：批量内容是“搭地基”，先跑量。

结论：启动“双线并行”；Sam 在分支开发自动化流程；内部链接映射表需提前准备；批量内容保证基本规范即可。
