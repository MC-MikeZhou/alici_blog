# AI Influencer Prompt Pack — 10 Monetization-Ready Photography Styles

> 4-layer architecture for consistent, production-quality AI influencer content.

---

## 4-Layer Prompt Architecture

```
Layer 0: Identity Anchor — Immutable features (face, body, distinctive marks)
Layer 1: Style Overlay — Lighting, lens, color, grain, post-processing
Layer 2: Scene & Pose — Story-driven context and positioning
Layer 3: Glamour Layer — Atmosphere-based appeal (mood, not explicit)
```

**How to use**: Start with Layer 0 (your character), add the style-specific layers below.

---

## Layer 0: Identity Anchor (Required for All Styles)

Replace the bracketed sections with your Character Bible details:

```
[Face shape] face, [eye color] eyes, [hair description], [skin tone], [age] years old, [distinctive marks], @[your_model_name], maintaining consistent facial features
```

**Example:**
```
Oval face, deep brown eyes with amber flecks, long dark wavy hair, light olive skin, early 20s, small beauty mark near left eye, @sofia_lux, maintaining consistent facial features
```

## Usage Tips

1. **Always start with Layer 0** — your character identity must anchor every prompt
2. **Mix layers carefully** — you can swap Scene layers between styles, but Style layers define the look
3. **Glamour layer is subtle** — it sets mood, not explicit content
4. **Save your @model first** — use Alici AI's @model system before bulk generation
5. **Generate 3-5 per style** — select the best for your Hero Set
