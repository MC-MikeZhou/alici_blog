## Lessons Learned

### What Worked Well

✅ **Tier System**: Automated tier detection (Tier 2) was accurate
✅ **Self-Check JSON**: Extremely helpful for validation and debugging
✅ **Citable Block Taxonomy**: Type system makes semantic value explicit
✅ **IMAGE_PLACEHOLDER v2.0**: Structured metadata will improve Editor automation
✅ **CTA Friction Alignment**: After-step-4 CTA placement makes intuitive sense

### What Could Improve

⚠️ **Self-Test Data**: Template data is better than nothing, but real data would add significant E-E-A-T value (+3 points)
⚠️ **Image Generation**: Still manual—Editor automation will help
⚠️ **Workflow Selector**: Could add value for multi-path tutorials, but not applicable to linear workflows

### Recommendations for Future Articles

1. **Collect experiment_pack data early**: Real testing data = +5 AEO points vs +2 for Self-Test
2. **Plan image strategy upfront**: 5 images with v2.0 metadata is significant work—allocate time
3. **Identify friction points during writing**: CTA placement is much better when planned vs retrofitted
4. **Use Self-Check JSON for validation**: Catches Tier mismatches and word count issues early
