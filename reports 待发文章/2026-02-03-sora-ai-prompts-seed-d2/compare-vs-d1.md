# D2 (Template Library) vs D1/V2 (Tutorial Playbook): Positioning Comparison

**Date**: 2026-02-03  
**Goal**: Make it easy to A/B test which format wins for creators and which queries they capture.

---

## What each post is trying to win

| Item | D1/V2 Tutorial (playbook) | D2 Templates (library) |
|---|---|---|
| User intent | “Teach me a system” | “Give me prompts now” |
| Primary success | Repeatable workflow adoption | Copy‑paste usage + quick wins |
| Best distribution | Search + internal linking + newsletters | Social shares + bookmarks + “save this” |
| Cannibalization risk | Can overlap with cinematic guide if not careful | Can overlap with generic “AI video prompts” lists |
| CTA logic | “Run workflow in alici.ai (Sora 2/Pro) + iterate” | “Paste template in alici.ai (Sora 2/Pro) + generate variations” |

---

## Query capture strategy

| Post | SEO anchor keyword | Supporting keywords (examples) | Why it matters |
|---|---|---|---|
| D1/V2 | “sora 2 prompt guide” | viral ugc ads, prompt framework, troubleshooting | Captures “guide/playbook” intent |
| D2 | “sora ai prompts” | prompt examples, best sora prompts, viral prompts | Captures “templates/examples” intent |

Note: Existing DataForSEO batch shows **AI video prompt templates = 0 volume**, so D2 should anchor on “prompts/examples” and use “templates” as value promise.

---

## Decision rule (what to publish / link / sequence)

- If you want **higher conversion per reader**: publish D1/V2 first, link to D2 as “template appendix”.
- If you want **faster creator pull**: publish D2 first (shareable), then link to D1/V2 as “full system”.
- Best cluster: D2 → D1/V2 → pillar `/blog/ai-video-guide` (and keep cinematic guide separate).
