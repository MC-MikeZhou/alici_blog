## Quick Answer

If you want viral-style UGC ads, don’t hunt for a “magic Sora prompt”. Use templates that force the right structure: **Hook (first second) + Proof moment + UGC realism cues + Simple pacing + Loop ending**. Then generate 6–12 variations and change **one** variable per run.

## How to Use This Template Library (So It Actually Works)

### Step 1: Pick ONE archetype (don’t mix them)

This library is grouped into 5 UGC ad archetypes:

| Archetype | Best for | What makes it “viral-ready” |
|---|---|---|
| Product-in-hand demo | Simple products, tactile features | Hands in frame + immediate action |
| Before → After proof | Clear result products | Proof is unmissable |
| Satisfying process | “Oddly satisfying” demos | Hook is the process itself |
| POV problem → solution | Pain-point products | Hook is the problem action |
| Proof close-up | Single feature sells | Tight framing + pause for proof |

### Step 2: Run the template ONCE as-is

Before you customize, run one template exactly as written. This prevents “prompt drift” where you change too many things and can’t tell what helped.

### Step 3: Generate 6 variations (one variable per run)

Choose one knob per run:
- hook action (peel / twist / wipe / snap / pour)
- framing (tight close-up vs medium close-up)
- background (kitchen counter vs bathroom sink vs desk)
- lighting (soft daylight vs warm indoor)
- pacing (pause for proof vs continuous)

<!-- CITABLE_BLOCK -->
> **Variations beat prompts**: the difference between “okay” and “great” is usually your iteration workflow - not a longer prompt.
<!-- /CITABLE_BLOCK -->

### Step 4: Pick top 2, then tighten with fix lines

Use the troubleshooting section below to add one fix line (product centered, pause for proof, handheld realism, hook first second) instead of rewriting everything.

### Archetype 1: Product‑in‑Hand Demo (5 templates)

#### 1) “Peel & Reveal” demo

```
Vertical UGC-style video, 9:16, realistic, authentic. Slight handheld feel.

Hook (first second): hand peels/removes [THING] to reveal [RESULT].
Proof moment: pause to clearly show [RESULT] for a beat.
Loop ending: end on the same framing as the opening shot.
```

## Troubleshooting: Viral Failure Modes (Fix Lines)

1) **Hook is slow/unclear**  
Fix line: `Hook in the first second: start with the main action immediately. No slow build.`

2) **Looks too cinematic (not UGC)**  
Fix line: `UGC realism: slight handheld feel, natural daylight, lived-in environment, hands in frame.`

3) **Proof isn’t visible**  
Fix line: `Product centered in frame. Pause to clearly show the proof moment for a beat.`

4) **Background distracts**  
Fix line: `Minimal background clutter. Shallow depth of field. Background softly blurred.`

5) **Too chaotic**  
Fix line: `One main action only. No sudden transitions. Camera movement minimal and steady.`

6) **Lighting hides the product**  
Fix line: `Soft diffused daylight, clean neutral palette, gentle shadows, no harsh glare.`

7) **Feels unrealistic / “AI-y”**  
Fix line: `Realistic textures and motion. Slight imperfections. Natural pacing. No stylization.`

## FAQ

### What are some really good AI prompts?

Good prompts are specific about what must be visible (hook + proof) and simple about everything else. Start with a template here, then change one variable per iteration.

### Can Sora AI generate anything?

Sora-like models can cover a wide range of scenes, but outputs depend heavily on how clearly you specify framing, action beats, and realism cues. Use templates to reduce ambiguity.

### Can you try Sora AI for free?

Access depends on the platform and your account plan. If you’re using alici.ai, you can run Sora 2 / Sora 2 Pro in AI Video Studio, then iterate quickly with the prompt assistant.

### Is Sora AI restricted?

Most platforms apply safety and policy restrictions. If a prompt is disallowed or outputs fail, simplify the scene and avoid sensitive content; focus on product/UGC-safe scenarios.

### Why do my prompts feel “too commercial”?

You likely over-specified cinematic camera language and perfect studio settings. Add UGC realism cues and remove cinematic terms.

### How do I keep results consistent across variations?

Lock style + lighting + environment lines, then change only one variable (hook action OR framing OR background) per run.
