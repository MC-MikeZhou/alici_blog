Editor Skill v2.2

战略图片生成 + 品牌视觉一致性

1. 核心理念："Less is More"

从 v2.0 开始，Editor Skill 不再机械填充所有图片占位符，而是以高级编辑的视角，战略性选择 3-5 个关键位置生成高质量、信息密集的图片。

设计哲学：3 张高质量图 > 10 张平庸图
成本控制：$0.15/张 × 3-5 张 = $0.45-0.75/篇文章

战略图片位置（文章位置百分比）

0% - Hero Cover

必须

设定视觉基调，吸引点击，品牌识别度最高。

2K 分辨率 16:9

33% - Concept Diagram

推荐

解释抽象概念，辅助理解复杂流程。

1K 分辨率 16:9

66% - Comparison Visual

推荐

展示差异，辅助决策，可视化对比。

1K 分辨率 16:9

100% - CTA/Summary

可选

驱动转化，总结要点。

1K 分辨率 16:9

2. ICSB Prompt 框架（v2.2 新增）

从 v2.1 的 ICS 框架升级到 ICSB，新增 Brand Layer 确保所有图片符合 alici.ai 品牌视觉规范。

组件 作用 示例
I - Image Type 图片格式 Editorial illustration, infographic, product shot
C - Content 3-5 个信息元素 Central element, symbolic representation, depth layers
S - Style 视觉美学 Composition, lighting, texture, format
B - Brand Layer NEW alici.ai 品牌识别 绿色中心色系 + Stripe 风格 + 40% 留白

3. 品牌视觉规范（BRAND_VISUAL_GUIDE.md）

核心要求

  • ✅ 绿色中心渐变：深绿 (#059669) → 中绿 (#10B981) → 浅绿 (#A7F3D0)
  • ✅ 40%+ 负空间：画面至少 40% 留白，呼吸感优先
  • ✅ 单一焦点：视觉焦点唯一且清晰
  • ✅ 抽象隐喻：用符号代替具象描绘
  • ✅ Stripe 风格：柔和 3D、平滑渐变、极简构图
  • ❌ NO 蓝紫色调：避免蓝色/紫色（Stripe 的品牌色）
  • ❌ NO 饱和色：避免过于鲜艳的颜色
  • ❌ NO 密集布局：避免信息堆砌

Brand Layer 模板（必须添加到所有 Prompt）

Brand aesthetic: alici.ai (Stripe-inspired, green-centered) Color palette: - GREEN-CENTERED gradient: deep emerald → fresh mint → light green - Soft, sophisticated transitions - Muted saturation Style elements: - Generous negative space (40%+) - Soft 3D with subtle shadows - Single focal point - Clean, breathable composition - Professional, trustworthy feel Avoid: Blue/purple, saturated colors, clutter, literal photos

4. 设计思路背后的考量

为什么选择 "Less is More"？

  • 用户体验：减少视觉干扰，聚焦关键信息
  • 加载速度：图片数量减少 50%+，页面加载更快
  • 成本控制：从 $1.20 降低到 $0.45/篇（-62.5%）
  • 品牌一致性：每张图都经过精心设计，而非批量生成

为什么需要 Brand Layer？

  • 视觉识别度：用户看到图片就能联想到 alici.ai
  • 专业性：避免"AI 生成感"，提升内容可信度
  • 差异化：与竞品拉开距离（大部分竞品用蓝紫色调）

为什么统一 16:9 比例？

  • 技术限制：Nano Banana Pro 不支持自定义尺寸，只能用 aspect_ratio + resolution
  • 响应式友好：16:9 在移动端和桌面端都有良好表现
  • Framer 兼容：Framer CMS 对 16:9 支持最好

Blog Tutorial Writer v2.0

AIDA 开篇框架 + AI 引用优化

1. 核心升级：AIDA 开篇框架

从 v1.0 的"简单直答"升级到结构化的 AIDA 框架（Attention → Interest → Desire → Action），提升开篇吸引力和 AI 引用概率。

组件 字数 作用 示例
Attention 40-60 词 直接答案（AI 提取点） "Creating viral AI videos requires 3 core elements: tool, prompt, format..."
Interest 20-30 词 痛点共鸣 "Struggling to keep up with viral trends? 78% of creators feel overwhelmed..."
Desire 20-30 词 价值承诺 "In this guide, you'll learn how to create viral AI videos from scratch..."
Action 10-20 词 快速导航 "> In a hurry? Jump to [Step-by-Step Guide](#steps)"
v1.0 开篇：40-60 词，单纯直答
v2.0 开篇：80-120 词，AIDA 结构化
效果：AI 引用率提升（预估 3x），用户参与度提升

2. Citable Block 标记系统

新增 <!-- CITABLE_BLOCK: Label --> 标记，优化 AI 答案引擎的内容提取。

要求

  • 数量：每篇文章 3-5 个
  • 分布：1 个在开篇/背景，2-3 个在主要步骤，1 个在结论/技巧
  • 长度：40-80 词
  • 特性：独立可理解、数据驱动、可直接引用

示例

5. 设计思路背后的考量

为什么需要 AIDA 框架？

  • AI 引用优化：Attention 部分提供清晰的直接答案，AI 引擎容易提取
  • 用户留存：Interest 和 Desire 提升参与度，降低跳出率
  • 导航友好：Action 提供快速跳转，改善用户体验

为什么需要 Citable Blocks？

  • AI 发现机制：ChatGPT/Perplexity 等 AI 答案引擎优先提取结构化、数据驱动的内容
  • 内容质量强制：要求每个 block 包含数据，倒逼写作质量提升
  • 竞品差异化：参考 supadata.ai 被 ChatGPT 发现的案例

为什么强化 E-E-A-T？

  • Google 算法：E-E-A-T 是 Google 核心排名因素
  • 可信度：完整的作者信息和引用提升内容可信度
  • 长期价值：高 E-E-A-T 内容在 AI 时代依然有价值

6. 后续优化方向

  • v2.1：外部引用验证（链接检查）

Framer Previewer v1.0

本地预览 + Framer 样式模拟

1. 核心功能

在导入 Framer CMS 前，本地生成 HTML 预览文件，模拟 Framer 渲染效果。

支持的输入

  • Markdown 文件：含 YAML frontmatter 的 .md 文件
  • JSON 文件：Framer CMS 格式的 .json 文件

输出

  • 07-preview.html：可在浏览器中打开的预览文件
  • 内容摘要：章节统计、图片数量、表格/列表统计

2. Framer 样式模拟

Markdown 元素 Framer 渲染 说明
## H2 <h6><strong> Framer 用 h6 渲染 H2
### H3 <p><strong> H3 变为加粗段落
- 列表项 <li data-preset-tag="p"><p> 列表项包含 data 属性
![图片](url) <figure><img></figure> 图片用 figure 包裹
表格 <figure><table></figure> 表格用 figure 包裹
链接 <a target="_blank"> 自动添加新窗口打开

3. 设计思路背后的考量

为什么需要预览工具？

  • 快速迭代：无需实际导入 Framer 就能查看效果
  • 布局验证：检查图片位置、表格格式、列表缩进
  • CTA 测试：验证按钮样式和链接是否正确
  • 团队协作：非技术人员也能轻松预览

为什么要模拟 Framer 样式？

  • 真实性：预览效果接近最终发布效果
  • 发现问题：提前发现 Framer 特殊渲染导致的问题
  • 品牌一致：使用 alici.ai 绿色主题，预览即品牌展示

4. 使用场景

  • 编辑完成后：检查图片是否正确插入
  • 转换前：在 markdown-to-framer 之前验证格式
  • 团队审核：分享 HTML 文件给非技术同事审核
  • 客户演示：快速展示文章效果

5. 当前限制

  • 图片 CDN：需要图片已上传到 CDN，本地路径可能无法显示
  • 交互功能：无法预览 Framer 的动画和交互效果
  • 响应式：预览主要针对桌面端，移动端效果可能有差异

💬 团队反馈与优化方向

当前需要反馈的重点

🎯 核心问题：Nano Banana Pro 提示词和视觉风格是否符合品牌预期？

1. 视觉风格反馈收集

  • 绿色色调：当前使用的绿色渐变（深绿 → 中绿 → 浅绿）是否满意？是否需要调整饱和度或明度？
  • 留白程度：40% 留白是否合适？是否需要更多/更少留白？
  • 抽象程度：当前的抽象符号化表达是否清晰？是否需要更具象一些？
  • 3D 效果：柔和的 3D 元素是否符合专业感定位？

2. Prompt 优化建议

请团队成员提供：

  • 参考图片：喜欢的配图风格案例（竞品或其他来源）
  • 调整建议：对现有图片的具体改进意见
  • 禁忌元素：不希望出现的视觉元素或风格

3. 反馈提交方式

方式 1: 参考图片

提供喜欢的图片 URL，Claude 会分析并提取设计元素更新规范。

方式 2: 文字描述

方式 3: 竞品参考
