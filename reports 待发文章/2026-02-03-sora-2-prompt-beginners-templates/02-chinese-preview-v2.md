## 主要章节

### 1) Quick Answer（爆款 UGC Prompt 公式）

**要点**:
- 直接给出可引用的“Viral UGC prompt formula”：
  - Hook（首秒）+ Proof（证据瞬间）+ Realism（真实感）+ One action beat（单动作节奏）+ Loop ending（可循环）
- 强调“变体流程”比单条 prompt 更重要：一次只改一个变量，批量出片

### 2) What Makes a UGC Ad Go Viral（用 Prompt 语言解释爆款）

**要点**:
- 把爆款要素翻译成可执行的 prompt 指令（首秒发生什么、proof 怎么“看得见”、UGC 真实感 cues、节奏、loop）
- 提供一张“Viral checklist”表格：Signal → 含义 → Prompt hint

### 3) 7 步爆款迭代流程（Step-by-step）

**要点**:
- 先选 UGC archetype（product-in-hand / before-after / satisfying process / POV / proof close-up）
- hook 用“画面动作句”写（不是字幕句）
- 定义 proof moment（必须看得见）
- 用 7 要素结构把 hook/proof 落到画面里
- 批量出 6–12 变体（一次只改一个变量）
- 用 viral checklist 选 top 2
- 最后减冲突、锁真实感、加 loop ending

### 4) Prompt Structure（UGC 版本的 7 要素 + 表格）

**要点**:
- Two strategies：Descriptive vs Directive（但例子全部是 UGC ad）
- 7 要素表格：Element → Viral leverage → Example line（AEO 加分）
- 给出一条完整“viral UGC prompt”示例
- 给出 UGC viral checklist（可复制）

### 5) 5 个爆款模板库（可复制）

**模板类型**:
1) Product-in-hand demo
2) Before → After proof
3) Satisfying process
4) POV problem → solution
5) Proof close-up shot

**每个模板都包含**:
- Hook beat 一句
- Proof beat 一句
- Loop ending 一句
- What to change（变量槽位）

### 6) Viral Failure Modes（爆款失败模式排错）

**新增更贴合 UGC 的症状**:
- hook 不清晰/太慢
- 太像“广告片”不像 UGC
- proof 看不见（产品不居中/太快/背景乱）
- 不够真实（太干净/太电影）

并提供可直接加回 Prompt 的 fix line（至少 7 条）。

### 7) CTA（落到 alici.ai）

**要点**:
- 明确操作路径：打开 alici.ai → AI Video Studio → 选 Sora 2 或 Sora 2 Pro → 粘贴模板 → 出 6 个变体 → 用 Prompt Assistant 微调赢家
