## What Makes a UGC Ad Go Viral (In Prompt Terms)

You can’t “prompt” your way into virality, but you can prompt for the ingredients that consistently improve UGC ad performance:

1. **Hook clarity (first second)**: something visually happens immediately.
2. **Proof moment**: a clear “this works” beat (result, comparison, feature demo).
3. **Pacing**: one main action beat with 1–2 supporting details (not a storyboard).
4. **UGC realism cues**: handheld, natural light, lived-in environment, slight imperfections.
5. **Loop ending**: an ending that can cut back to the start seamlessly.

### Viral checklist (quick scoring)

| Signal | What it means | Prompt hint |
|---|---|---|
| Hook is instant | Viewer sees the “why” immediately | Start with an action beat, not adjectives |
| Proof is visible | Result/feature is unmissable | “Product centered in frame” + “pause to show proof” |
| Looks like UGC | Feels filmed by a person, not a studio | “slight handheld feel”, “natural daylight” |
| Pace is simple | Easy to follow in 6–10 seconds | “one main action only”, “calm, steady movement” |
| Loopable ending | End can connect to the beginning | “ends on the same framing as the opening” |

## Step-by-Step: Viral UGC Prompt Workflow (7 Steps)

### Step 1) Choose a UGC ad archetype

Pick ONE archetype before you write anything:
- Product‑in‑hand demo
- Before → After proof
- “Satisfying process” demo
- POV problem → solution
- Proof close‑up shot

### Step 2) Write your hook as a VISUAL action (one sentence)

Good hook sentence:
> “A hand peels off the protective film, revealing the screen instantly.”

Bad hook sentence:
> “A cool product in a modern setting.”

### Step 3) Define your proof moment (what must be seen?)

Pick one proof moment:
- a clear result (before/after)
- a key feature working (click, twist, clean, seal)
- a comparison moment (two items, one wins)

### Step 4) Build the prompt using the 7-element structure (UGC version)

You’ll use a consistent structure so you can iterate without chaos:
- Format & style
- Camera feel + framing
- Location
- Lighting + palette
- Action beats (hook → proof → loop)
- (Optional) dialogue
- (Optional) audio cues

### Step 5) Generate 6–12 variations (change ONE variable each time)

Variation knobs (choose one per run):
- hook action
- framing (close-up vs medium)
- lighting (soft daylight vs warm indoor)
- background (kitchen counter vs bathroom sink)
- pacing (“pause to show proof” vs continuous)

### Step 6) Pick the top 2 using the viral checklist

Pick clips that:
- show the product clearly
- hit hook and proof quickly
- look like real UGC (not a commercial)
- feel loopable

### Step 7) Tighten the winner (reduce conflicts + lock realism + add loop)

Final pass:
- remove extra adjectives
- restate realism cues
- add “product centered” and “pause to show proof”
- add loop ending instruction

## Understanding Prompt Structure for Sora 2 (UGC Ad Edition)

### Two Prompt Strategies

**Descriptive Prompts** (Beginner)  
Describe the vibe and let the model fill in the “how”.

Example:
```
Vertical UGC-style clip in a bright kitchen. Natural daylight. A hand quickly shows a gadget,
then demonstrates the key feature in one simple motion. Clean, trustworthy.
```

**Directive Prompts** (Control)  
Direct how it’s filmed and what must be visible.

Example:
```
Vertical UGC-style video, 9:16, realistic. Slight handheld feel.
Camera: close-up on hands and product, product centered.
Action: hook in first second, then pause to clearly show the result.
```

### 7 Essential Prompt Elements (and how they drive “viral”)

| Element | Viral leverage | Example line |
|---|---|---|
| Format & Style | Makes it feel like UGC (not studio) | “Vertical UGC-style video, 9:16, realistic” |
| Camera & Lens | Keeps product/proof visible | “close-up, product centered in frame” |
| Location & Framing | Reduces distraction | “minimal kitchen counter, shallow background clutter” |
| Lighting & Color | Makes proof easy to see | “soft diffused daylight, clean neutral palette” |
| Motion & Action Beats | Controls pace & clarity | “one main action only; pause to show proof” |
| Dialogue (optional) | Adds meaning without subtitles | “Subject says: ‘Watch this.’” |
| Audio cues (optional) | Suggests realism | “room tone, subtle kitchen ambience” |

### Complete Prompt Example (viral UGC)

```
Vertical UGC-style video, 9:16, realistic, authentic.
Camera: close-up on hands and product, slight handheld feel, product centered in frame.
Location: kitchen counter, lived-in but uncluttered, shallow depth of field.
Lighting: soft diffused daylight, clean neutral color palette.
Action beats:
1) Hook (first second): hand peels the protective film quickly.
2) Proof moment: pause to show the clean reveal clearly for a beat.
3) Loop ending: end on the same framing as the opening shot.
Optional audio cues: subtle room tone, light kitchen ambience.
```

### Prompt Checklist (UGC viral)

- [ ] Hook happens in the first second (visual action)?
- [ ] Proof moment is unmissable (product centered + pause)?
- [ ] Realism cues included (handheld + natural light + lived-in environment)?
- [ ] One main action beat (no storyboard)?
- [ ] Loop ending specified (end framing matches opening)?
- [ ] Only one variable changed per variation?

## 5 Copy-Paste Templates for Viral UGC Ads (And What to Change)

> Rule: run a template ONCE as-is. Then change only the variables listed under “What to change”.

### Template 1: Product‑in‑hand demo (hands + natural light)

```
Vertical UGC-style video, 9:16, realistic. Slight handheld feel.
Close-up on hands and [PRODUCT], product centered in frame.
Natural daylight, clean neutral tones, lived-in kitchen counter.
Hook: hand picks up [PRODUCT] and does [HOOK ACTION] in the first second.
Proof moment: pause to clearly show [PROOF RESULT] for a beat.
Loop ending: end on the same framing as the opening.
```

What to change: `[PRODUCT]`, `[HOOK ACTION]`, `[PROOF RESULT]`, background (kitchen/bathroom/desk).

### Template 2: Before → After proof (result is the star)

```
Vertical UGC-style video, 9:16, realistic. Slight handheld feel.
Close-up framing so the before/after difference is obvious.
Soft diffused daylight, neutral palette.
Hook: show the BEFORE state instantly (first second).
Proof moment: reveal the AFTER state clearly and hold for a beat.
Loop ending: end with the BEFORE framing so it can loop.
```

What to change: before/after subject, reveal motion, hold time (“pause to show proof”).

### Template 3: “Satisfying process” demo (operation feels good)

```
Vertical UGC-style video, 9:16, realistic.
Camera: close-up on hands, slight handheld feel, product centered.
Lighting: soft natural light, warm-neutral tones.
Hook: start with the most satisfying moment (first second): [SATISFYING ACTION].
Proof moment: show the outcome clearly (clean finish / smooth result).
Loop ending: finish with a reset motion that returns to the opening position.
```

What to change: satisfying action, surface/environment, proof outcome.

### Template 4: POV problem → solution (hook = pain)

```
Vertical UGC-style POV video, 9:16, realistic.
Camera: handheld POV, medium close-up, lived-in environment.
Hook: show the problem instantly (first second): [PROBLEM ACTION].
Proof moment: introduce [PRODUCT] and solve it in one simple motion.
Loop ending: end on the same problem framing as the opening.
```

What to change: problem action, product, solution motion.

### Template 5: Proof close-up shot (one feature wins)

```
Vertical UGC-style video, 9:16, realistic.
Camera: tight close-up, product centered, slight handheld feel.
Lighting: bright, even, minimal shadows for clarity.
Hook: immediate close-up of [FEATURE] moving/working (first second).
Proof moment: pause to show the feature state/result clearly.
Loop ending: end by returning the feature to the starting position.
```

What to change: feature, environment, proof state, reset motion.

## Viral Failure Modes (Symptoms → Causes → Fix Prompt Lines)

### 1) Symptom: Hook is unclear / too slow

Cause: the prompt starts with mood words, not action.  
Fix line:
```
Hook in the first second: start with the main action immediately, no slow build.
```

### 2) Symptom: Looks like a polished commercial, not UGC

Cause: too cinematic, too perfect, too “studio”.  
Fix line:
```
UGC realism: slight handheld feel, natural daylight, lived-in environment, minimal set dressing.
```

### 3) Symptom: Proof moment isn’t visible (viewer can’t “see it works”)

Cause: product not centered; proof too fast; cluttered background.  
Fix line:
```
Product centered in frame. Pause to clearly show the proof moment for a beat. Minimal background clutter.
```

### 4) Symptom: Too much happens at once (chaotic pacing)

Cause: multiple actions + camera moves.  
Fix line:
```
One main action only. No sudden transitions. Camera movement is minimal and steady.
```

### 5) Symptom: Lighting makes the product/proof hard to read

Cause: vague “mood” without lighting direction.  
Fix line:
```
Lighting: soft diffused daylight, clean neutral palette, gentle shadows, no harsh glare.
```

### 6) Symptom: Feels unreal / “AI-y”

Cause: overly perfect surfaces, exaggerated motion, stylized look.  
Fix line:
```
Realistic textures and motion. Slight imperfections. Natural pacing. No stylization.
```

### 7) Symptom: The model ignores the key action

Cause: action buried under adjectives; too many goals.  
Fix line:
```
Action beats (in order): hook first, then proof moment, then loop ending. Keep everything else secondary.
```

## Pro Tips (Creator Workflow)

1. Write your hook as an action, not a caption.
2. Treat “proof moment” as a required beat - if it’s not visible, it won’t convert.
3. Batch 6–12 variations and change only one variable per run.
4. For UGC realism: hands in frame + natural light + lived-in setting beats “cinematic language”.
5. Add “pause to show proof” more often than you think.
6. Always specify product framing (“product centered”) when you care about conversion.
7. Add a loop ending so the clip can replay cleanly.

### What is the fastest way to make a UGC ad feel “viral” in the first second?

Start with a strong visual action (hook) and keep the prompt simple. “Hook first second” + “product centered” + “pause to show proof” is a reliable baseline.

### Should I use short prompts or long prompts for UGC ads?

Start short for exploration and variations. Go longer only when you need control over framing, proof visibility, and realism cues.

### Why does my clip feel too “commercial”?

You likely over-specified cinematic camera language or made the setting too perfect. Add handheld realism cues and remove cinematic terms.

### How do I keep outputs consistent across variations?

Lock your style lines (UGC realism, lighting, environment) and change one variable per run (hook action OR framing OR background).

### Do these templates work on other AI video tools?

Mostly yes. The structure (hook → proof → loop, realism cues, product framing) transfers well, even if wording needs small adjustments per model.
