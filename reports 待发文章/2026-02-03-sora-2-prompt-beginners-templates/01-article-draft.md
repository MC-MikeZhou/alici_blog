## AIDA Opening

Most “Sora 2 prompt” advice fails beginners because it’s either too cinematic or too vague.

In practice, your results improve fastest when you treat prompts like a **repeatable workflow**, not a creative writing exercise.

This guide gives you a copy‑paste prompt skeleton, a 7‑step beginner workflow, and a troubleshooting playbook you can reuse across Sora 2 and other AI video tools.

If you want fewer failed generations and more usable clips, start with the Quick Answer and run the templates exactly as written once before you customize.

## Key Takeaways (TL;DR)

- Use a **prompt skeleton** (format → camera → location → light → action → optional dialogue/audio) to keep outputs consistent.
- Start with **short prompts** to explore, then add detail only to fix one problem at a time.
- Debug prompts like a checklist: **symptom → likely cause → minimal fix** (don’t rewrite everything).

## Quick Answer (Copy This Prompt Skeleton)

To write a good Sora 2 prompt as a beginner, use a simple structure: **Format/Style + Camera + Location + Lighting + One clear action**, then iterate by fixing one symptom at a time with small prompt edits.

```

[CAMERA & LENS] (movement + framing).

[LIGHTING & COLOR].
```

## Step-by-Step: A 7-Step Prompt Workflow (0 → First Good Clip)

### Step 1) Define the deliverable (what are you making?)

Pick one:
- A 6–10 second **Reels/Shorts clip**
- A **UGC-style product demo**
- A **lifestyle b-roll montage**

Write a single sentence deliverable:

> “A short vertical clip showing a hand using a product in a bright kitchen, designed for UGC ads.”

### Step 2) Choose a single “hero” subject (don’t start with a crowd)

Good beginner subjects:
- one person
- one product
- one animal
- one simple environment shot

Avoid at the start:
- crowds, fast action, multiple characters, complicated transformations

### Step 3) Lock the look (format + style) before you think about camera

Decide:
- Style: realistic / documentary / commercial / anime / claymation
- Aspect ratio: 9:16 vs 16:9
- Texture: clean / grainy / vintage / high-contrast

If you change style every iteration, you’ll never know what fixed the problem.

### Step 4) Add camera direction (one move + one framing)

As a beginner, limit yourself to one:
- **Static** wide/medium/close-up
- **Slow push-in** (dolly-in)
- **Simple follow** (tracking behind)

### Step 5) Add environment + lighting (to control mood)

Specify:
- Where it happens (kitchen, street, studio backdrop)
- Time of day (morning, golden hour, night neon)
- Light quality (soft diffused, harsh direct, backlit rim light)

### Step 6) Describe the action in one beat (one verb, one outcome)

One beat:
> “The hand opens the box and places the product on the table.”

Not a storyboard:
> “Open box, smile, walk, jump cut, transition, spin, slow motion, fireworks…”

### Step 7) Iterate using “symptom → fix” (minimal edits)

When the output is wrong, do not rewrite the whole prompt. Do this instead:

1. Name the symptom (blurry / wrong framing / weird motion)
2. Guess the cause (too vague / conflicting instructions)
3. Add a *minimal fix line* and rerun

## Understanding Prompt Structure for Sora 2

### Two Prompt Strategies

**Descriptive Prompts** (Beginner)  
Use sensory details and let the model decide the “how”.

Example:
```
A cozy morning kitchen, soft window light, warm tones. A hand places a small gadget
next to a cup of coffee. Calm, clean, minimal.
```

**Directive Prompts** (Professional)  
You tell the model exactly how to “film” the scene.

Example:
```
Vertical commercial footage, 9:16. Medium close-up. Slow push-in.
Soft diffused daylight from the left. The hand opens the box and reveals the product.
```

Most strong prompts blend both: directive for control, descriptive for taste.

### 7 Essential Prompt Elements

1. **Format & Style**
2. **Camera & Lens**
3. **Location & Framing**
4. **Lighting & Color Palette**
5. **Motion & Action Beats**
6. **Dialogue Blocks (optional)**
7. **Audio Cues (optional)**

### “What to say” vs “what to leave out” (beginner rule)

| Element | Say this | Avoid this |
|---|---|---|
| Style | “UGC-style handheld”, “cinematic commercial”, “documentary” | 10 styles at once (“cinematic anime documentary…”) |
| Camera | “static medium close-up”, “slow push-in” | multiple moves in one clip (“orbit + drone + handheld”) |
| Action | one clear verb (“opens”, “pours”, “walks”) | long choreography with many steps |
| Lighting | “soft diffused daylight”, “neon reflections on wet street” | vague mood only (“make it cool”) |

<!-- CITABLE_BLOCK -->
> **The fastest way to improve prompt results** is to reduce conflicts: *one subject, one main action, one camera move, one lighting setup.*
<!-- /CITABLE_BLOCK -->

### Complete Prompt Example (short vs long)

**Short prompt (explore)**
```
Vertical UGC-style video, 9:16. Soft daylight kitchen.
Close-up of a hand opening a product box and placing the item on the table.
Clean, natural colors.
```

**Long prompt (control)**
```
Vertical UGC-style commercial footage, 9:16, realistic, clean and modern.
Camera: medium close-up, slight handheld feel, slow push-in over 3 seconds.
Location: bright kitchen countertop, minimal background clutter, shallow depth of field.
Lighting: soft diffused daylight from the left, gentle shadows, warm neutral color palette.
Action: a hand opens the box, pauses to reveal the product clearly, then places it beside a cup of coffee.
Mood: calm, trustworthy, product-first, no dramatic effects.
Optional audio cues: quiet room tone, subtle kitchen ambience.
```

### Prompt Checklist (copy/paste)

- [ ] Format & style defined?
- [ ] Aspect ratio specified (9:16 vs 16:9)?
- [ ] One camera move + one framing?
- [ ] Location + framing cues included?
- [ ] Lighting quality + palette included?
- [ ] One main action beat (one verb)?
- [ ] Any optional dialogue/audio kept minimal?
- [ ] No conflicting instructions?

## Copy-Paste Prompt Templates (And What to Change)

### Template 1: Beginner “0→1” test prompt

**Use when**: you’re testing if your idea works at all.

```
[FORMAT & STYLE]. [ASPECT RATIO].
Static [FRAMING]. [LOCATION]. [LIGHTING].
[SUBJECT] does [ONE ACTION]. Calm, clean, natural.
```

**Change only**:
- subject
- one action
- location

### Template 2: UGC product-in-hand clip (creator-friendly)

```
Vertical UGC-style video, 9:16, realistic.
Camera: medium close-up, slight handheld, slow push-in.
Bright kitchen, soft diffused daylight.
A hand holds [PRODUCT], shows the key feature, then places it on the counter.
Clean, trustworthy, product-first.
```

**Change only**: product + key feature action (twist/open/press/peel).

### Template 3: “Lifestyle b-roll” aesthetic clip

```
Vertical lifestyle b-roll, 9:16, warm natural tones.
Camera: slow pan, medium shot.
Golden hour light. Cozy environment.
[SUBJECT] performs [ONE SIMPLE ACTION]. Soft, calm mood.
```

### Template 4: “Before → After” transformation (beginner-safe)

```
Vertical video, 9:16, clean commercial style.
Two-shot sequence feel (but keep it simple): first shows [BEFORE], then shows [AFTER].
Soft even lighting, neutral palette.
Action: [SUBJECT] changes from [BEFORE] to [AFTER] smoothly, no chaos.
```

### Template 5: Talking-head style (script-first)

> If your model setup supports speech, keep dialogue short. Otherwise, use the script to guide facial expression and pacing.

```
Vertical video, 9:16, documentary style.
Camera: static medium close-up, eye-level.
Soft diffused light. Neutral background.
Subject speaks: "[ONE SHORT LINE]".
Calm, clear, trustworthy.
```

## Common Mistakes (Symptoms → Fix Prompts)

### 1) Symptom: The video looks “random” or chaotic

- Likely cause: too many actions, multiple camera moves, conflicting styles
- Fix: remove actions; keep one beat; add “no dramatic effects”

Fix line:
```
One main action only. No sudden transitions. No dramatic effects. Calm pacing.
```

### 2) Symptom: Wrong framing (too wide / too close)

- Likely cause: missing framing language
- Fix: specify shot type + subject size

Fix line:
```
Framing: medium close-up on the hands and product, product centered in frame.
```

### 3) Symptom: Lighting feels off (too dark / muddy colors)

- Likely cause: “mood words” without lighting direction
- Fix: specify light source + quality + palette

Fix line:
```
Lighting: soft diffused daylight from the left, clean neutral tones, gentle shadows.
```

### 4) Symptom: Motion is weird (jittery / unnatural)

- Likely cause: too much motion + no constraints
- Fix: slow the action + simplify camera move

Fix line:
```
Smooth, slow movement. No jitter. Camera movement is minimal and steady.
```

### 5) Symptom: The subject changes style mid-clip

- Likely cause: style not locked; prompt contains mixed style cues
- Fix: restate the style explicitly and remove competing styles

Fix line:
```
Style locked: realistic UGC commercial, clean modern look, no stylization.
```

### 6) Symptom: The scene is cluttered / background distracts

- Likely cause: environment not constrained
- Fix: describe background as minimal and defocused

Fix line:
```
Minimal background clutter. Shallow depth of field. Background softly blurred.
```

### 7) Symptom: The model ignores the key action

- Likely cause: action buried in adjectives; multiple actions compete
- Fix: put action on its own line, first

Fix line:
```
Action: the hand opens the box and clearly reveals the product to camera.
```

### 8) Symptom: It feels “too cinematic” for UGC

- Likely cause: cinematic camera language (orbit, crane, extreme grading)
- Fix: explicitly request UGC style and keep camera simple

Fix line:
```
UGC-style handheld feel. Simple camera. Natural colors. Not cinematic.
```

## Pro Tips for Consistent Results

1. **Lock style early**: treat style as a “constant,” not a variable.
2. **Change one thing per iteration**: otherwise you won’t know what worked.
3. **Write actions as verbs**: “opens”, “pours”, “turns”, “walks” beats adjectives.
4. **Use camera language sparingly**: one move per clip is enough for beginners.
5. **Use “negative constraints” gently**: “no chaos / no fast cuts / minimal background” can help.
6. **Keep a prompt log**: save versions so you can roll back to the last good one.
7. **Build a template library**: start with 3 templates and customize with variable slots.

## FAQ

### What is the easiest way to improve a Sora 2 prompt?

Reduce conflicts: **one subject, one main action, one camera move, one lighting setup**, then iterate with minimal fixes.

### Should I write short prompts or long prompts?

Start short to explore and confirm the idea. Go longer only when you need control—add detail to fix a specific problem, not “because more words feels safer.”

### How do I keep my video style consistent across variations?

Make style a constant: repeat the same **format/style + lighting + palette** lines in every version, and change only the subject/action variables.

### Why does my output look chaotic?

Chaotic outputs usually come from too many actions and camera moves in one prompt. Simplify to one beat, and add “calm pacing” and “no sudden transitions.”

### How do I write prompts for UGC-style ads?

Use simple camera language (static or slight handheld), natural lighting, a minimal background, and one product-first action beat (hold → show feature → place down).

### Can I reuse the same prompting system on other AI video tools?

Yes. The structure (format → camera → location → lighting → action) and the “symptom → fix” iteration loop transfer well across video generators.
