# Quick AEO Score Framework for Competitive Validation

> 版本: 1.0 | 日期: 2026-01-20
> 用途: 快速评估竞品文章的 AEO 优化程度

## 概述

这是一个简化的 AEO 评分框架，用于快速评估竞品文章质量。
相比完整的 100 分 AEO 评分，此框架聚焦于最关键的 4 个维度，满分 50 分。

## 评分维度

| 维度 | 满分 | 占比 | 评估焦点 |
|------|------|------|---------|
| 结构清晰度 | 15 | 30% | 内容是否易于 AI 提取 |
| 直接回答 | 10 | 20% | 开篇是否直接回答核心问题 |
| E-E-A-T 信号 | 15 | 30% | 可信度和权威性信号 |
| 内容新鲜度 | 10 | 20% | 内容时效性 |

---

## Dimension 1: 结构清晰度 (15 分)

### 1.1 标题层级结构 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 清晰的 H2/H3 层级，章节明确，每个 H2 下有相关 H3 |
| 3 | 有 H2/H3 结构，但层级不够清晰或部分缺失 |
| 1 | 仅有 H2 或标题结构混乱 |
| 0 | 无明显标题结构，或只有 H1 |

**检查方法**:
```
- 统计 H2 数量: 理想 4-8 个
- 统计 H3 数量: 每个 H2 下 2-4 个
- 检查层级逻辑: H3 是否属于对应 H2 的子主题
```

### 1.2 列表与表格使用 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 有列表 AND 表格，用于呈现关键信息 |
| 3 | 有列表 OR 表格，但使用不够充分 |
| 1 | 少量列表或表格，大量纯文本段落 |
| 0 | 纯文本墙，无结构化数据呈现 |

**检查方法**:
```
- 列表数量: 理想 3+ 个
- 表格数量: 理想 1+ 个
- 位置: 关键信息是否用列表/表格呈现
```

### 1.3 FAQ 部分存在 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 有独立 FAQ 章节，包含 3+ 个相关问题 |
| 3 | 有 Q&A 格式内容，但不是独立章节或问题较少 |
| 1 | 有零星 Q&A 元素 |
| 0 | 无 FAQ 或 Q&A 内容 |

**检查方法**:
```
- 查找 "FAQ", "常见问题", "Questions" 等标题
- 统计问答对数量
- 检查问题是否与文章主题相关
```

## Dimension 2: 直接回答 (10 分)

### 2.1 开篇直答质量 (10 分)

| 分数 | 标准 |
|------|------|
| 10 | 前 50 词内直接回答核心问题，40-60 词完整答案 |
| 7 | 前 100 词内回答，但不够直接或简洁 |
| 4 | 答案在前 200 词内，但被背景信息包围 |
| 2 | 开篇是背景/历史/定义，答案在后面 |
| 0 | 开篇是纯营销/钩子，无实质答案 |

**检查方法**:
```
提取前 100 词，回答以下问题:
1. 读者能否在前 50 词获得核心问题的答案?
2. 答案是否具体明确 (vs 模糊泛泛)?
3. 是否使用了直接的陈述句 (vs 疑问/引导)?
```

**理想开篇模式**:
```
[直接答案，40-60 词]
[简短扩展说明，30-50 词]
[文章预告/目录，可选]
```

## Dimension 3: E-E-A-T 信号 (15 分)

### 3.1 作者信息 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 命名作者 + 头像 + 简介/职位/经验描述 |
| 3 | 命名作者 + 基本信息 (无详细背景) |
| 1 | 仅有作者名或 "Team" / "Staff" |
| 0 | 无作者信息或完全匿名 |

**检查方法**:
```
- 查找 byline: "By [Name]", "Written by", "Author:"
- 查找作者简介区块
- 检查是否有社交链接 (LinkedIn, Twitter)
```

### 3.2 外部来源引用 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 5+ 个外部权威来源链接/引用 |
| 3 | 2-4 个外部来源 |
| 1 | 1 个外部来源或仅内部链接 |
| 0 | 无外部来源引用 |

**检查方法**:
```
- 统计外部链接数量
- 检查来源类型: .edu, .gov, 行业权威网站 = 高质量
- 检查是否有内联引用 (如 "According to [Source]...")
```

### 3.3 案例/数据/测试 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 有原创案例研究、测试数据、或一手经验分享 |
| 3 | 有示例或截图，但非原创测试 |
| 1 | 有通用示例，无具体数据 |
| 0 | 纯理论阐述，无案例或数据支持 |

**检查方法**:
```
- 查找 "n=X", "我们测试了", "In our experience"
- 查找具体数字/百分比/统计
- 查找截图、视频、对比图
```

---

## Dimension 4: 内容新鲜度 (10 分)

### 4.1 发布/更新日期 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 30 天内发布/更新 |
| 4 | 90 天内发布/更新 |
| 3 | 6 个月内发布/更新 |
| 2 | 1 年内发布/更新 |
| 1 | 超过 1 年，但有日期显示 |
| 0 | 无日期或超过 2 年 |

**检查方法**:
```
- 查找 "Published:", "Updated:", "Last modified:"
- 查找 Schema 中的 datePublished/dateModified
- 检查 URL 中的日期 (如 /2026/01/)
```

### 4.2 内容时效性 (5 分)

| 分数 | 标准 |
|------|------|
| 5 | 提及当前年份数据/版本/事件 |
| 3 | 内容普遍适用，无明显过时信息 |
| 1 | 有部分过时信息 (旧版本、已更改的功能) |
| 0 | 明显过时 (引用已停止服务、旧版界面等) |

**检查方法**:
```
- 查找年份引用: "2026", "2025"
- 检查版本号是否最新
- 检查价格/功能是否与当前一致
```

## 分数换算

将 50 分制快速评分换算为 100 分制，用于与我们的 AEO 分数对比：

```
换算公式: (快速评分 / 50) × 100 = 100分制分数

示例:
- 38/50 → 76/100
- 32/50 → 64/100
- 25/50 → 50/100
```

## 评分检查清单

### 快速评估流程

```
□ Step 1: 打开竞品页面
□ Step 2: 滚动浏览，评估结构清晰度 (15分)
    - H2/H3 数量和层级
    - 列表/表格使用
    - FAQ 存在
□ Step 3: 阅读开篇 100 词，评估直接回答 (10分)
    - 前 50 词是否有答案
    - 答案是否具体明确
□ Step 4: 查找 E-E-A-T 信号 (15分)
    - 作者信息
    - 外部链接
    - 案例/数据
□ Step 5: 检查新鲜度 (10分)
    - 发布/更新日期
    - 内容时效性
□ Step 6: 汇总分数，记录到报告
```

### 单篇评估时间

目标: **2-3 分钟/篇**

- 结构评估: 30 秒
- 开篇评估: 30 秒
- E-E-A-T 评估: 1 分钟
- 新鲜度评估: 30 秒
- 记录汇总: 30 秒

## 常见竞品类型与基准

| 竞品类型 | 典型分数 | 特征 |
|----------|---------|------|
| **官方文档** | 30-40 | 结构好，但无作者/案例 |
| **营销型博客** | 20-30 | 缺直答，E-E-A-T 弱 |
| **专业博客** | 35-45 | 全面，有案例和数据 |
| **新闻稿** | 15-25 | 无结构，纯事实堆砌 |
| **论坛帖子** | 10-20 | 无结构，匿名 |
