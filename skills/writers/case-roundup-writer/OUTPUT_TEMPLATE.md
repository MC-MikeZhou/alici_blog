## Section Guidelines

### Title (H1)

**Format**: Question or statement, 40-60 characters

**Examples**:
- ✓ "Motion Control 让动作生成更准确了吗？"
- ✓ "为什么 Kling 2.6 的 Motion Control 值得关注"
- ✗ "Motion Control 使用指南" (too generic)
- ✗ "AI 视频新功能介绍" (too vague)

### Direct Answer

**Length**: 2-3 sentences, 40-60 words total

**Structure**:
- Sentence 1: Direct answer to title question (核心观点 + 关键证据)
- Sentence 2 (optional): "Why now" context

**Example**:
```
是的，Motion Control 将动作生成的确定性从"prompt 猜测"变成"reference 迁移"。通过提供参考视频，创作者可以精确控制动作轨迹，而不再依赖 AI 对文字描述的理解。

Kling 2.6 的 Motion Control 功能发布后，已有大量案例验证了这一点。
```

### Key Takeaways

**Format**: 3-5 bullet points, each 10-20 words

**Content**:
- Derived from Insight Pack `key_takeaways`
- Actionable and specific
- Pattern-focused language

**Example**:
```
- Reference video 是动作蓝图，AI 直接复制轨迹而非猜测意图
- Prompt 应聚焦场景/风格，避免重复描述动作本身
- 选择 Camera Motion: Static 模式可提高动作迁移准确度
- 参考视频的清晰度和动作明显度直接影响生成质量
```

### Case Studies (2-5 cases)

**Each case structure**:

1. **Case Title**: Concise, descriptive (5-10 words)
2. **What happens**: 80-100 words
   - Concrete, visual description
   - What tool/technique was used
   - What result was achieved
3. **Why it works**: 30-40 words (1-2 sentences)
   - Technical explanation or design logic
   - Focus on "paradigm shift" or "certainty improvement"
4. **What to copy**: 2-3 actionable items
   - Specific, replicable practices
   - Key elements for success
   - Optional: advanced techniques

**Example** (full case):
```markdown
### Case 1: 舞蹈动作迁移到虚拟角色

**What happens**: 创作者使用一段真人舞蹈视频作为动作参考，通过 Kling 2.6 的 Motion Control 功能，将舞蹈动作精确迁移到 AI 生成的虚拟角色上。最终视频中，虚拟角色完美复现了参考视频中的舞步节奏和肢体动作，但场景和角色风格完全不同。

**Why it works**: Motion Control 将动作确定性从 prompt 文字描述（AI 需要"猜测"你想要什么动作）变成了 reference 迁移（AI 直接复制参考视频的动作轨迹）。这避免了文字描述的歧义性。

**What to copy**:
- 使用清晰、全身入镜的舞蹈视频作为参考源
- Prompt 聚焦于场景和风格描述，不要重复描述动作本身
- 选择"Camera Motion: Static"模式以提高动作迁移准确度
```

### How to Try It

**Format**: Numbered list, 最多 4 步

**Each step**: 15-25 words

**Focus**: High-level workflow, not UI details

**Example**:
```markdown
1. 找一个清晰、全身入镜的参考视频（舞蹈、运动、手势等）
2. 在 alici.ai Video Studio 中选择 Kling 2.6 + Motion Control 模式
3. 上传参考视频，编写场景/风格 prompt（不描述动作）
4. 选择 Camera Motion: Static，生成后检查动作准确度
```

### Mini FAQ (3 questions)

**Format**: H3 question + paragraph answer

**Each answer**: 40-60 words

**Question sources**:
- User's likely questions after reading cases
- Technical clarifications
- Limitations or trade-offs

**Example**:
```markdown
### Motion Control 支持哪些视频平台？

Kling 2.6 的 Motion Control 支持上传本地视频文件（MP4, MOV）作为参考。推荐使用 5-10 秒的短片段，过长的视频可能导致处理时间增加或生成失败。
```

### Source Note & Product Integration

**Source Note**: 1 sentence stating where cases came from

**Product Integration**: 1-2 sentences, educational narrative, NOT promotional CTA

**Example**:
```markdown
**Source Note**: 本文案例来自 3 个 YouTube 视频观察和 1 次内部测试。

*使用 [alici.ai Video Studio](https://app.alici.ai/pages/videoGen) 可以在一个平台上切换 Kling、Runway、Veo 等多个模型，无需学习多个工具的操作界面。*
```
