# Prompt Templates for Alici Blog Covers

Complete prompt templates for each background type. Replace bracketed variables with appropriate values.

## Base Prompt Structure

```
Create a minimalist tech blog cover image for Alici.AI.

[BACKGROUND DESCRIPTION]

Typography:
[TEXT SPECIFICATIONS]

Text position: [POSITION DESCRIPTION]

Style: Ultra-minimalist, generous negative space, clean typography hierarchy.
Professional tech aesthetic. No decorative elements beyond specified.

Aspect ratio: 16:9
Resolution: 1920x1080
```

## Type 1: Gradient Glow

### Template

```
Create a minimalist tech blog cover image for Alici.AI.

Background: Pure black (#000000) with a soft, organic teal gradient ([COLOR])
emanating from the [POSITION], fading smoothly into darkness.
The gradient should feel like diffused light or gentle aurora.
No hard edges, no texture, no noise.

Typography:
- Main title: "[H1_TEXT]" in bold white (#FFFFFF) sans-serif typography
  (similar to Inter Black), large and prominent
- [OPTIONAL] Secondary: "[H2_TEXT]" in bold white, 50% size of main title
- [OPTIONAL] Subtitle: "[H3_TEXT]" in regular white at 70% opacity, 25% size
- Brand tag: "Officially on Alici.AI" in small regular white at 60% opacity,
  positioned at bottom

Text position: [TEXT_POSITION]

Style: Ultra-minimalist, generous negative space (60%+ dark),
clean typography hierarchy. Professional tech aesthetic.

Aspect ratio: 16:9
Resolution: 1920x1080
```

### Variables

**COLOR options:**
- `#4FD1C5` - Core Teal (default)
- `#81E6D9` - Light Teal
- `#319795` - Deep Teal

**POSITION options:**
- `top-left corner`
- `bottom-right corner`
- `left edge`
- `right edge`
- `top edge, flowing downward`

**TEXT_POSITION options:**
- `Centered, slight bias toward lower third`
- `Left-aligned, vertically centered`
- `Center-left, leaving right for gradient`

### Example

```
Create a minimalist tech blog cover image for Alici.AI.
```

## Type 2: Fluid Shape

### Template

```
Create a minimalist tech blog cover image for Alici.AI.

Background: Pure black (#000000) with a single abstract fluid shape
in teal ([COLOR]). The shape should look like [FLUID_TYPE],
smooth and organic, occupying approximately 25-35% of the frame.
Position it in the [ELEMENT_POSITION], leaving generous negative space.
Soft glow around edges, no hard boundaries.

Typography:
- Main title: "[H1_TEXT]" in bold white (#FFFFFF) sans-serif typography
  (similar to Inter Black), large and prominent
- [OPTIONAL] Secondary: "[H2_TEXT]" in bold white, 50% size of main title
- [OPTIONAL] Subtitle: "[H3_TEXT]" in regular white at 70% opacity, 25% size
- Brand tag: "Officially on Alici.AI" in small regular white at 60% opacity

Text position: [TEXT_POSITION]

Style: Ultra-minimalist, generous negative space (50%+ dark),
clean typography hierarchy. Professional tech aesthetic.
The fluid shape and text should feel balanced but not symmetrical.

Aspect ratio: 16:9
Resolution: 1920x1080
```

### Variables

**COLOR options:**
- `#4FD1C5` - Core Teal (default)
- `#81E6D9` - Light Teal
- `#319795` - Deep Teal

**FLUID_TYPE options:**
- `a flowing ribbon of light` - motion/transformation content
- `a soft liquid blob` - organic/creative content
- `a gentle wave form` - audio/sound content
- `molten glass in slow motion` - premium/artistic content

**ELEMENT_POSITION options:**
- `upper right area`
- `lower left area`
- `center-right`
- `upper left, flowing toward center`

**TEXT_POSITION options:**
- `Left-center area, leaving right side for the fluid element`
- `Right-center area, leaving left side for the fluid element`
- `Lower left, with fluid element above`

### Example

```
Create a minimalist tech blog cover image for Alici.AI.

Background: Pure black (#000000) with a single abstract fluid shape
in teal (#4FD1C5). The shape should look like a flowing ribbon of light,
smooth and organic, suggesting motion and transformation.
It flows from the upper right toward center-left, occupying approximately
30% of the frame. Soft glow around edges, no hard boundaries.

Typography:
- Main title: "IMAGE → VIDEO" in extra-bold white (#FFFFFF) sans-serif
  typography (similar to Inter Black), very large
- Secondary: "Workflow" in bold white, 50% the size of main title
- Subtitle: "Nano Banana Pro + Kling 2.6" in regular white at 70% opacity
- Brand tag: "Officially on Alici.AI" in small regular white at 60% opacity

Text position: Left-center area, leaving right side for the fluid element.

Style: Ultra-minimalist, generous negative space (50%+ dark),
clean typography hierarchy. Professional tech aesthetic.

Aspect ratio: 16:9
Resolution: 1920x1080
```

## Type 3: Geometric Minimal

```
Create a minimalist tech blog cover image for Alici.AI.

Background: Pure black (#000000) with minimal geometric elements
in teal ([COLOR]). [GEOMETRIC_ELEMENT]
The geometry should be clean, precise, with subtle glow.
Very minimal - less is more. 60-70% of frame remains pure black.

Typography:

  (similar to Inter Black), large and prominent
- [OPTIONAL] Secondary: "[H2_TEXT]" in bold white, 50% size of main title
- [OPTIONAL] Subtitle: "[H3_TEXT]" in regular white at 70% opacity, 25% size
- Brand tag: "Officially on Alici.AI" in small regular white at 60% opacity

Text position: [TEXT_POSITION]

Style: Ultra-minimalist, precise, technical aesthetic.
Clean typography with geometric accent.

Aspect ratio: 16:9
Resolution: 1920x1080
```

### Variables

**COLOR options:**
- `#4FD1C5` - Core Teal (default)
- `#64748B` - Slate (for neutral content)

**GEOMETRIC_ELEMENT options:**
- `A single thin horizontal line with soft glow, positioned in upper third`
- `Two parallel diagonal lines, subtle gradient along their length`
- `A large circle outline (stroke only, no fill) positioned off-center, partially cropped by frame edge`
- `A simple grid of small dots, sparse, fading toward edges`
- `A single thin vertical line on the right third, with soft glow`
- `Three horizontal lines of varying length, stacked with even spacing`

**TEXT_POSITION options:**
- `Centered, with geometric element as accent`
- `Left-aligned, geometric element on right`
- `Below the geometric element`

## Type 4: Typography-Led

```

in [GLOW_POSITION], almost imperceptible, just enough to add depth.
The visual interest comes entirely from typography hierarchy and scale contrast.
No decorative elements.

Typography (this is the main visual element):
- Line 1: "[H1_LINE1]" in [WEIGHT1] white (#FFFFFF) sans-serif, [SIZE1]
- [OPTIONAL] Line 2: "[H1_LINE2]" in [WEIGHT2] white, [SIZE2]
- [OPTIONAL] Line 3: "[H2_TEXT]" in regular white at 70% opacity
- Brand tag: "Officially on Alici.AI" in small regular white at 60% opacity

Text position: [TEXT_POSITION]

Style: Typography-driven design, text scale and weight create visual hierarchy.
Ultra-clean, bold, professional.

Aspect ratio: 16:9
Resolution: 1920x1080
```

### Variables

**COLOR options:**
- `#4FD1C5` - Core Teal (default)
- `#319795` - Deep Teal (more subtle)

**GLOW_POSITION options:**
- `center`
- `bottom area`
- `corners`
- `behind the text`

**WEIGHT/SIZE combinations:**
- `extra-bold, very large` - primary emphasis
- `bold, large` - secondary emphasis
- `regular, medium` - tertiary

**TEXT_POSITION options:**
- `Centered vertically and horizontally`
- `Left-aligned, vertically centered`
- `Stacked vertically, center-aligned`

### Example

```
Create a minimalist tech blog cover image for Alici.AI.
```

## Quick Reference: Content → Type Mapping

| Content Type | Primary Type | Backup Type | Color |
|--------------|--------------|-------------|-------|
| Model release | Type 1 or 4 | Type 2 | Core Teal |
| Feature tutorial | Type 2 | Type 3 | Core Teal |
| Motion/video features | Type 2 | Type 5 | Core Teal |
| Comparison/review | Type 5 | Type 3 | Slate |
| Technical docs | Type 6 | Type 3 | Core Teal |
| Workflow guide | Type 3 | Type 5 | Core Teal |
| Major announcement | Type 4 | Type 1 | Core Teal |
| Audio features | Type 2 (wave) | Type 5 | Light Teal |
