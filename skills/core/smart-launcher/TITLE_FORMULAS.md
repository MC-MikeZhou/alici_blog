## Listicle 榜单类

### 基础公式

```
[Number] + Best + [Product Category] + for/in + [Year]
```

**示例**:
- "10 Best AI Video Generators For 2026"
- "10 Best AI Tools for Social Media Content Creation in 2026"

### 扩展变体

| 变体 ID | 公式模板 | 适用场景 |
|---------|----------|----------|
| `listicle_big_number` | `[N] Most Useful [Category] Tools In [Year]` | 超大型榜单 (20+) |
| `listicle_prompt` | `[N] Best [X] with Prompts + workflows` | AI 工具榜单 |
| `listicle_platform` | `[N] Best [X] for [Platform]` | YouTube/TikTok 专项 |
| `listicle_device` | `[N] Best Free [X] for [Device]` | Android/iPhone 专项 |
| `listicle_dual_device` | `[N] Best [X] for Desktop and Mobile` | 全设备覆盖 |
| `listicle_beginner` | `[N] Best [X] (Beginner Friendly and Easy)` | 初学者定位 |
| `listicle_tested` | `[N] Best [X]: Tried & Tested` | 强调测试权威 |

**示例**:
- "29 Most Useful Social Media Marketing Tools In 2026"
- "14 Best AI Video Generators with Prompts + workflows"
- "13 Best Video Editing Softwares for YouTube"
- "10 Best Free Video Editing Apps for Android"
- "11 Best Online Video Editors (Beginner Friendly and Easy)"
- "10 Best AI Image Generators: Tried & Tested"

## Showdown 对决类

### 核心公式

```
[Brand A] vs [Brand B] vs [Brand C] vs [Brand D]: [Value Question]
```

**关键点**: 4 个品牌是最佳数量，问句结尾增加点击欲望

| 变体 ID | 公式模板 | 特点 |
|---------|----------|------|
| `showdown_question` | `[A] vs [B] vs [C]: Which [Category] Wins?` | 问句结尾 |
| `showdown_comparison` | `[A] vs [B]: Which is Better for [Use Case]?` | 双品牌对比 |

**示例**:
- "Kling vs Sora vs Veo vs Runway: Which AI Model Wins?"
- "Midjourney vs DALL-E: Which is Better for Marketing?"

## 标题公式选择指南

### 按目标选择

| 目标 | 推荐公式 |
|------|----------|
| 帮人选择工具 | Listicle, Showdown, Alternatives |
| 教人做事 | How-to, Guide |
| 展示发现 | Trends, Feature |
| 建立权威 | Statistics |

### 按内容长度选择

| 长度 | 推荐公式 |
|------|----------|
| 短篇 (300-2,000) | `howto_time`, `trends_feature` |
| 中篇 (2,000-3,500) | `showdown_question`, `alternatives_basic` |
| 长篇 (3,500-8,000) | `howto_ultimate`, `listicle_tested`, `stats_ignore` |

### 标题必备元素

1. **必须包含年份** (SEO 新鲜度信号)
2. **数字选择**: 10 是最常用 (心理锚点)，统计类用具体大数字 (84, 135)
3. **品牌提及**: 自家产品在标题中用 "beginner-friendly" 定位而非 "best"
