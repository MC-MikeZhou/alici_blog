## 周三 - 素材验证与初稿生成

### 3. 验证素材可用性（20 分钟）

**对每个素材检查：**
- [ ] Notion 链接能否打开？
- [ ] 内容完整吗？（没有缺页）
- [ ] 图片能否加载？
- [ ] 是否需要登录权限？
- [ ] 内容是否最新？

**问题处理：**
```
❌ 链接无法打开
→ 寻找替代来源或联系素材提供者

❌ 需要登录权限
→ 导出 PDF 再上传到 Notion

❌ 内容过时（> 6 个月）
→ 标记为"信息过时"，寻找更新版本

✅ 一切正常
→ 继续下一步
```

### 4. 启动内容生成（2-4 小时）

**按照快速指南的 7 步流程执行：**

```
Step 1: 准备素材 (10 min)
  → 确认 Notion 链接正确发布

Step 2: 选择类型 (5 min)
  → News / Tutorial / List

Step 3: 验证素材 (20 min)
  → 链接都能打开

Step 4: 生成中文预览 (60 min)
  → AI 生成初稿

Step 5: 审核预览 (30 min)
  → 你看一遍，可能小改

Step 6: 生成最终版本 (45 min)
  → AI 自动翻译、配图、生成 JSON

Step 7: 完成发布 (5 min)
  → 确认输出文件
```

## 周四 - 终稿审核与优化

### 5. 最终质量检查（30 分钟）

**打开 `./output/[title]_output.json`，检查：**

#### A. 内容质量检查

```
内容完整性：
- [ ] 标题吸引人且不超过 100 字
- [ ] TLNR（摘要）清晰且 50-150 字
- [ ] 开篇能立即抓住读者
- [ ] 逻辑流畅，无跳跃
- [ ] 结尾有强有力的 CTA
- [ ] 总长度符合要求（News 1.2-1.8k, Tutorial 1.8-2.5k, List 2-3k）

语言质量：
- [ ] 无明显语法错误
- [ ] 英文翻译自然流畅
- [ ] 专业术语使用恰当
- [ ] 品牌语气一致
- [ ] 没有生硬的关键词堆砌
```

#### B. SEO 检查

```
关键词优化：
- [ ] 主关键词在标题中出现
- [ ] 主关键词在摘要中出现
- [ ] meta_title 中有关键词（50-60 字）
- [ ] meta_description 清晰（100-160 字）
- [ ] tag_for_SEO 有 4-6 个相关词
- [ ] 关键词密度 1-2%（不堆砌）

标题结构：
- [ ] H6 标题 5-10 个（news 5-6, tutorial 5-7, list 6-10）
- [ ] 每个标题包含关键词或价值主张
- [ ] 标题顺序逻辑合理
```

#### C. 配图检查

```
- [ ] 封面图有效（可以打开）
- [ ] 封面图尺寸 16:9
- [ ] 文章内配图有效
- [ ] 配图与文字搭配恰当
- [ ] 没有版权问题
```

#### D. 格式检查

```
JSON 格式：
- [ ] 文件名格式正确（title_timestamp_output.json）
- [ ] JSON 格式有效（可用 JSON 编辑器打开）
- [ ] 所有必需字段都有值
- [ ] URL 字段都是有效的 HTTP/HTTPS 链接
- [ ] 日期格式正确（ISO 8601）

HTML 格式（article_body_content）：
- [ ] 段落标签正确 <p>...</p>
- [ ] 标题标签正确 <h6>...</h6>
- [ ] 列表格式正确 <ul><li>...</li></ul>
- [ ] 链接格式正确 <a href="...">...</a>
- [ ] 图片格式正确 <img src="...">
```

**评分表：**
```

格式规范: ___/100
```

## 常见问题快速查询

### Q: 我的文章发布后一直排名不好？

**可能原因 + 检查清单：**
```
❌ 关键词选择不当
→ 用 Google Trends 或 Ahrefs 重新研究
→ 选择月搜索量 1,000-10,000 的词（竞争适中）

❌ 标题不够吸引
→ 对比前 3 名竞品的标题
→ 看看是否需要加"2025"、"完整指南"等词

❌ 内容质量不足
→ 检查是否比竞品内容更深入
→ 是否包含独特的数据或案例

❌ 反向链接太少
→ 发起 PR（新闻稿）推广
→ 联系行业博客引用

❌ 发布时间太短
→ Google 通常需要 4-12 周才能给予排名
→ 持续监测，可能需要等待
```

### Q: 应该多久发布一篇新文章？

**推荐：** 每周 2-3 篇

**理由：**
- 太少（1 篇/月）：搜索引擎难以认为你是活跃的内容源
- 太多（10+ 篇/周）：难以保证质量，可能被认为是垃圾内容

**发布节奏示例：**
```
周二-周四：选题 + 生成 + 发布 (2 篇)
周四-周五：继续发布 (1 篇)

这样每周发布 2-3 篇，且有充分质量控制时间
```

### Q: SEO 关键词应该怎么选？

**步骤：**
```
1. 头脑风暴 20 个相关词
2. 用 Google Trends / Ahrefs / SEMrush 评估
   - 搜索量 > 500/月（有搜索量）
   - 竞争度 < 0.5（容易排名）
3. 按"商业价值"排序
   - 1 级：直接相关产品功能 (How to use Alici?)
   - 2 级：相关教程 (How to create AI headshots?)
   - 3 级：行业知识 (What is AI? How does AI work?)
4. 优先写 1 级和 2 级关键词的文章
```

**示例：**
```
AI Headshots (头部词)
├─ 1 级：How to create AI headshots
├─ 1 级：Best AI headshot tools 2025
├─ 2 级：AI headshots vs traditional photography
├─ 2 级：AI headshot pricing comparison
└─ 3 级：What are AI headshots

我们的优先顺序: 1 级 > 2 级 > 3 级
```
