## 第一部分：核心概念（5分钟）

### 这个系统是什么？

AliciBlog 帮助你快速生成**高质量、SEO优化的博客内容**。

你输入原始素材 → 系统通过规范化流程 → 输出可直接发布的 JSON 数据

### 三种内容类型

| 类型 | 用途 | 长度 | 生成时间 |
|------|------|------|---------|
| **News** | 宣布新功能、产品更新 | 1,200-1,800 词 | 45-90 分钟 |
| **Tutorial** | 教用户如何做某事 | 1,800-2,500 词 | 60-120 分钟 |
| **List** | 精选工具/资源对比 | 2,000-3,000 词 | 90-180 分钟 |

### 最终输出是什么？

一个 JSON 文件，包含：
- 文章标题、摘要、内容
- SEO 元数据（标题、描述、关键词）
- 配图链接
- 可直接导入 Framer CMS

**文件位置：** `./output/[文章标题]_[时间戳]_output.json`

## 第二部分：7步快速流程

### 全流程概览（2-4小时）

```
准备素材 → 选择类型 → 验证素材 → 生成预览 → 审核预览 → 生成发布物 → 完成
 (10min)   (5min)    (20min)    (60min)    (30min)    (45min)    (5min)
```

### Step 1: 准备原始素材（10分钟）

#### 方式A：Notion 链接（推荐）
最稳定、内容完整的方式

**操作步骤：**
1. 在 Notion 中编辑你的素材页面
2. 点击右上角 "Share" → "Publish to web"
3. 复制公开链接

**示例：**
```
https://www.notion.so/Your-Article-Title-12345abc...
```

**提示：**
- ✅ Notion 链接发布后不要关闭，图片需要持续访问
- ✅ 可以提供多个 Notion 链接，系统会合并内容
- ❌ 不要在 Notion 中包含最终版本，那是 AI 生成的地方

#### 方式B：本地文本文件
适合纯文字素材

**操作步骤：**
1. 在项目文件夹中找到 `./input/` 目录（不存在的话新建一个）
2. 把 `.txt` 文件放进去
3. 可以放多个文件，系统会自动合并

**文件名称：** 任意，例如 `ai_video_source.txt`

#### 方式C：网页 URL
适合从网上采集内容

**支持情况：**
- ✅ **完美支持：** 新闻网站（如 CNN）
- ⚠️ **部分支持：** Notion 公开链接
- ❌ **不支持：** ChatGPT 分享链接

**提示：** 如果普通 URL 无法识别，可以尝试 `https://r.jina.ai/${url}` 的方式

---

### Step 2: 选择内容类型（5分钟）

#### News（新闻/更新）

**何时选择：**
- 宣布新功能上线
- 产品有重大更新
- 发布公司公告

**内容结构：**
1. 开篇：直接说"什么是新的"
2. 背景：解释为什么重要
3. 功能介绍：详细说明
4. 使用方法：3-5 步教程
5. 实际应用场景：2-3 个案例
6. 开始使用：告诉用户怎么访问
7. 未来展望：说说下一步计划
8. 结论：强有力的 CTA

**特点：** 兴奋但可信的语气，更多 CTA

---

#### Tutorial（教程）

**何时选择：**
- 教用户如何用某个工具
- 发布分步操作指南
- 详细解释某个概念

**内容结构：**
1. 引言：说清楚用户能学到什么
2. 背景：为什么值得学
3. 5-7 个详细步骤：每步 300-400 词
4. 常见错误：3-5 个要避免的坑
5. 专家技巧：3-5 个进阶小技巧
6. 结论：总结 + CTA

**特点：** 实用、友好、行动导向

---

#### List（精选列表）

**何时选择：**
- 对比 10+ 个工具或产品
- 总结"最好的"某类资源
- 提供选择指南

**内容结构：**
1. 引言：说清楚这个列表的价值
2. 背景：行业趋势和为什么重要
3. 10-20 个列表项：每项 150-200 词
4. 对比表格：3-5 个维度
5. 选择指南：告诉不同用户选哪个
6. 快速开始：如何使用
7. 结论：顶级推荐 + CTA

**特点：** 客观、权威、数据驱动

---

### Step 3: 验证素材可用性（20分钟）

#### Notion 链接
- 用浏览器打开链接，确保能看到内容和图片
- 如果显示"不存在"或"无权限"，需要重新发布

#### 本地文本文件
- 检查文件编码是 UTF-8
- 文件不超过 5MB

#### 网页 URL
- 用浏览器打开，确保内容完整
- 注意是否需要登录

---

### Step 4: 生成中文预览版（60分钟）

这一步会生成一个 HTML 文件，用浏览器就能打开，看到文章的完整样子（包括配图）。

#### 操作流程

1. **启动 AI 聊天工具**
   - 使用 Claude Code、Gemini、Codex 任意一个
   - 进入项目文件夹

2. **给 AI 输入提示**

   ```
   查看项目的 readme.txt，然后开始。

   我要生成一篇 [News/Tutorial/List] 文章。

   素材是：
   - [Notion 链接1]
   - [Notion 链接2]
   （或本地 txt 文件、其他 URL）
   ```

3. **审核 AI 生成的中文预览版**
   - 打开 `./tmp/chinese_preview.html` 文件
   - 用浏览器查看效果
   - 检查：
     - 内容逻辑是否清晰？
     - 有没有遗漏重要信息？
     - 配图位置是否合理？
     - 语气是否符合你的期望？

4. **需要修改的话告诉 AI**

   ```
   预览版有几处需要修改：
   1. 第二段的描述太复杂，简化一下
   2. 在"Step 3"后面加一个配图
   3. 最后的 CTA 改成"开始使用"而不是"立即购买"

   然后重新生成预览版。
   ```

5. **确认满意后**

   ```
   中文预览版确认无误，请继续生成最终的发布内容。
   ```

---

### Step 5: 审核预览版（30分钟）

这一步只需要你审核，不用做什么。

**检查清单：**
- [ ] 标题吸引人吗？
- [ ] 开篇能否立即吸引读者？
- [ ] 内容逻辑清晰吗？
- [ ] 有没有语法或拼写错误？
- [ ] 配图和文字搭配合理吗？
- [ ] CTA（号召行动）够有力吗？
- [ ] 整体长度合适吗？（不要太长也不要太短）

**反馈给 AI：**
```
预览版看起来很好。有两个小改进：

1. 第一句改成："在 2025 年..."（加个年份参考）
2. 最后一段的 CTA 改成："现在就试试"而不是"点击这里"

修改后就可以进行下一步了。
```

---

### Step 6: AI 生成最终发布内容（45分钟）

AI 会自动：
1. ✅ 生成配图（如果需要）
2. ✅ 生成封面图
3. ✅ 将中文内容翻译成英文
4. ✅ 生成 SEO 元数据（标题、描述、关键词）
5. ✅ 组织成 JSON 格式

**你需要批准的步骤：**

#### 6.1 配图与 SEO 优化
AI 会问："需要自动生成配图吗？"

- **选择"是"** - AI 会根据内容自动生成合适的配图并上传
- **选择"否"** - 跳过配图，仅使用素材本身的图片

#### 6.2 最终 JSON 输出
AI 会生成一个 JSON 文件，包含：

```json
{
  "Slug": "how-to-...",           // 网址
  "title": "How to...",           // 英文标题
  "TLNR": "Learn how to...",      // 摘要
  "cover": {...},                 // 封面图
  "article_body_content": "...",  // 完整正文
  "meta_title": "...",            // SEO 标题
  "meta_description": "...",      // SEO 描述
  "tag_for_SEO": "..."            // 关键词
}
```

**验证清单：**
- [ ] title 和 meta_title 是英文吗？
- [ ] 关键词合理吗？
- [ ] 文章长度符合要求吗？
- [ ] 配图链接有效吗？

---

### Step 7: 完成发布（5分钟）

生成好的文件会自动保存到：

```
./output/[文章标题]_[时间戳]_output.json
```

**下一步：**
1. ✅ 下载这个 JSON 文件
2. ✅ 导入到 Framer CMS
3. ✅ 发布到网站

## 第三部分：常见问题

### Q1: 我不想让 AI 自动配图，可以自己找图片吗？

**A:** 完全可以。在 Step 4，告诉 AI "不需要自动生成配图"，AI 会保留你素材中原有的图片。

### Q2: 翻译成英文的质量如何？需要人工校对吗？

**A:** AI 翻译质量通常很高（80-90% 准确），但建议：
- 看一遍，检查是否有明显的语法错误
- 对于关键的 CTA 文案，手工审核一下
- 不需要完全重译，只需要 spot-check

### Q3: 中文预览版太长了，如何缩短？

**A:** 告诉 AI 哪些部分可以删除或缩写。例如：
```
这篇内容有点长。可以：
1. 减少 Step 5 的细节，从 400 词减到 250 词
2. 删除"Pro Tips"部分
3. 保留其他内容不变

重新生成预览版。
```

### Q4: 想要更改某个章节的标题或结构？

**A:** 完全可以。告诉 AI：
```
预览版很好，但我想改一下结构：

不要"常见错误"章节，改成"最佳实践"
内容从原来的"为什么会出错"改成"怎样做效果最好"

重新生成。
```

### Q5: 能否创建多个主题的 Blog，把最好的整合成一篇？

**A:** 可以。只需在 Step 1 提供多个 Notion 链接或 txt 文件，AI 会自动合并和组织。

### Q6: 生成的时间真的只需要 2-4 小时吗？

**A:** 是的，但这些时间是指：
- 你提供素材的时间：10 分钟
- 等待 AI 处理的时间：50-180 分钟（取决于内容长度和类型）
- 你审核和反馈的时间：30-60 分钟

**关键是：你不需要从零开始写内容，AI 会替你做大部分工作。**

### Q7: 用这个系统生成的文章能在 Google 排名好吗？

**A:** 有很好的机会。因为：
- ✅ 系统规范包含 SEO 最佳实践
- ✅ 生成的内容长度和结构符合 Google 偏好（1,200-3,000 词）
- ✅ 包含关键词和长尾关键词
- ✅ 有明确的标题层级和结构

但排名最终还是取决于：
- 内容质量（我们已经尽力了）
- 反向链接数量（需要 PR/营销配合）
- 发布频率（建议每月至少 1-2 篇）
- 网站整体权重（需要长期积累）

### Q8: 能否重复使用某篇文章的结构，快速生成相似的内容？

**A:** 可以。你可以：
1. 基于已发布的文章，创建新的 Notion 链接
2. 告诉 AI："基于[旧文章标题]的结构，用这些新素材生成新文章"
3. AI 会快速生成结构相似的内容（时间可能减少 30-40%）

### Q9: 如果中间出错了怎么办？

**A:**
- 清空 `./tmp/` 文件夹中的临时文件
- 关闭 AI 工具重新启动
- 从 Step 1 重新开始
- 通常不会遇到严重问题，因为整个流程很稳定

### Q10: 系统支持多语言吗？比如生成中文 + 日文版本？

**A:** 目前只支持中文→英文。如果需要其他语言，AI 可以在生成英文后，再翻译成其他语言，但这会增加 30-60 分钟的时间。

## 第六部分：常见错误与修复

### 错误1：Notion 链接发布后立即关闭，导致图片无法加载

**症状：** 预览版中图片显示为空白

**修复：**
- 重新在 Notion 中发布链接（别关闭）
- 等待 24 小时让图片缓存同步
- 重新生成预览版

---

### 错误2：文本文件上传到 input 文件夹后忘记清空，导致新旧素材混乱

**症状：** AI 混合了多篇文章的内容

**修复：**
- 清空 `./input/` 文件夹（只保留当前这篇的素材）
- 重新开始

---

### 错误3：选错了内容类型

**症状：** 生成出来的结构不对

**修复：**
- 告诉 AI："我选错了类型，这篇应该是 [正确类型]，请重新生成"
- AI 会按新类型重新组织内容

---

### 错误4：生成的英文翻译有明显错误

**症状：** 某些句子读起来很奇怪

**修复：**
- 在 Step 5 时告诉 AI："第 X 段的翻译有问题，改成：[你的版本]"
- 或让 AI 重新翻译某个特定段落
