### 👔 产品经理

**核心问题：** "这个系统是什么？我应该怎么改进它？"

**推荐阅读顺序：**
1. ✅ **《产品架构总览》** (15 分钟)
   - 了解系统定位、架构、代码规模
   - 看懂 4 阶段迭代方案
   - 评估投入成本和 ROI

2. ⭐ **《周运营检查清单》** (10 分钟)
   - 了解当前如何运营
   - 参考性能指标和目标设定

3. 📖 **《原项目 readme.txt》** (5 分钟)
   - 查看完整工作流程细节
   - 理解各个步骤的关键点

**关键数据点：**
- 系统现状：文档驱动、无代码、9 个文件
- 代码规模：32 KB 规范、8 KB readme、5.5 MB 视觉参考
- 月产能：5 篇文章 → 目标 18 篇（Phase 4）
- 成本：$100/篇 → $20/篇（自动化后）
- 投入：总 580-845 小时，分 9 个月

### 🖊️ 内容编辑 / 内容制作者

**核心问题：** "我如何快速生成一篇高质量博客？"

**推荐阅读顺序：**
1. ✅ **《快速上手指南》** (20 分钟)
   - 学会 7 步流程
   - 理解 3 种内容类型
   - 掌握常见问题处理

2. ⭐ **《周运营检查清单 - 质量检查部分》** (15 分钟)
   - 学会最终检查清单
   - 知道发布前要检查什么

3. 📖 **对应的规范文档** (根据文章类型，20-30 分钟)
   - 若写 Tutorial：读 `4_Tutorial类内容规范.md`
   - 若写 List：读 `5_List类内容规范.md`
   - 若写 News：读 `6_News类内容规范.md`

**快速参考：**
- 生成时间：2-4 小时/篇
- 关键工具：AI（Claude/Gemini）
- 输出物：JSON 文件 → 导入 Framer CMS
- 最常见错误：Notion 链接发布后关闭、txt 文件堆积、没有预审核

**一句话工作流：**
```
准备素材 → 选择类型 → AI 生成中文预览 → 审核 → AI 生成最终版本 → 发布
```
