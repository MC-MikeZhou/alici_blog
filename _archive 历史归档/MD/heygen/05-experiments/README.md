## 实验指标

每个实验记录以下数据：

### 技术指标
- **API 调用次数** - HeyGen 请求数
- **生成时间** - 从请求到完成的时长
- **视频时长** - 最终视频长度
- **文件大小** - 输出视频大小

### 成本指标
- **HeyGen 成本** - API 调用费用
- **Remotion 渲染成本** - 计算资源消耗
- **总成本** - 完整流程花费

### 质量指标
- **口型同步度** - 1-5 分评分
- **背景融合度** - 数字人与背景的协调性
- **整体效果** - 主观评价
