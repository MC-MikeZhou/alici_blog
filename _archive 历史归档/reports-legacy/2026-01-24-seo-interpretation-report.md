## 五、为什么 Kling Motion Control 搜索量为 0？

### 根本原因

| 原因 | 说明 |
|------|------|
| **功能太新** | Motion Control 是 Kling 2024 年底才推出的功能 |
| **品牌认知低** | Kling (快影) 在欧美市场知名度远低于 Runway/Pika |
| **搜索词过于具体** | 用户更可能搜索通用词 "ai video" 而非 "kling motion control" |
| **需求未建立** | 用户不知道这个功能存在，无法形成搜索行为 |

### 鸡生蛋问题

```
没有内容 → 用户不知道功能 → 不搜索
    ↑                          ↓
 没人写内容 ← 看起来没需求 ← 不搜索
```

**打破循环的方式**: 借势大词，将 Kling 内容嵌入已有搜索需求的话题
